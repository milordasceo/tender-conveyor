Рутина «Проверка папки «К рассмотрению»»: проверь папку «К рассмотрению» на Google Диске. Есть папки тендеров — каждую внеси в Notion и сразу перенеси в «Госзакупки/CRM/». Потом проверь цель дня.

Доступ к Диску: через rclone, remote `gosplan:`. Вход — `gosplan:Госзакупки/К рассмотрению`, каждая подпапка — один тендер, имя папки — номер тендера. Выход — `gosplan:Госзакупки/CRM`: папка там значит «уже в Notion, повторно не проверять». Уровня города нет, город — из `tender.json` → `delivery.city`.

1. Получи список номеров: `rclone lsf --dirs-only 'gosplan:Госзакупки/К рассмотрению'`.
2. В Notion найди страницу «К рассмотрению» и в ней базу «Тендеры».
3. Для каждого номера по одному:
   - скачай свежие `tender.json`, `tender.md`, `цены.md` в `/home/box/sysadmin/work/<номер>/` (папку перед этим очисти);
   - нет `tender.json` / `tender.md`, файлы битые или в `tender.md` нет раздела «Расчёт рентабельности» — ничего не создавай, папку не переноси, сразу напиши главному боту Тэндер Мэн (`<id Тэндер Мэна>`) номер и причину; переходи к следующему;
   - прибыль и расходы возьми из раздела «Расчёт рентабельности» в `tender.md`: прибыль — наибольшая «Прибыль варианта X», расходы — закупка + доставка + налог того же варианта (сумму посчитай сам);
   - «Откуда забирать» — поставщик лучшего варианта из `цены.md` (название, адрес, телефон компании); «Куда везти» — адрес доставки из `tender.json` и важное из примечаний (этаж, подъём, разгрузка); «2ГИС: откуда» и «2ГИС: куда» — ссылки `https://2gis.ru/<город латиницей>/search/<адрес в URL-кодировке>` (Новосибирск → `novosibirsk`), в адресе только город, улица и дом — без компании, индекса, телефона, этажа и примечаний; «Чистая прибыль» — формула, не заполнять; всё остальное — из `tender.json`;
   - проверь, что номера нет в базе. Нет — создай строку в «Тендеры» со всеми свойствами (Номер тендера, Полная цена, Прибыль, Расходы, Город, Категория, Количество поставок, Откуда забирать, Куда везти, 2ГИС: откуда, 2ГИС: куда, Подача до, Предмет, Ссылка), подходящим эмодзи и телом из разделов: Главное (первым — зелёный callout 💰 с жирной «Чистая прибыль: <сумма> ₽», сумма прибыли жирно на зелёной подложке, у адресов откуда/куда — «📍 2ГИС») → Особые условия (с «Особыми пометками») → Сроки → Что поставляем → Где купить (у каждого поставщика — «📍 2ГИС» и сайт из строки «Ссылка:» цены.md, в том числе домены xn--… и .рф) → Расчёт рентабельности → Заказчик и закупка (в нём строка «Папка на Диске: Госзакупки / CRM / <номер>»). Номер уже есть — новую строку не создавай;
   - открой строку и проверь, что свойства заполнены. Строки нет или она не открылась — папку не переноси, сообщи Тэндер Мэну;
   - строка есть — перенеси папку целиком: `rclone moveto 'gosplan:Госзакупки/К рассмотрению/<номер>' 'gosplan:Госзакупки/CRM/<номер>'`. Если в «CRM» папка с таким номером уже есть — не переноси и не затирай, сообщи Тэндер Мэну. Проверь листингом, что папка в «CRM» и её нет в «К рассмотрению»;
   - сразу после переноса отправь Тэндер Мэну одно сообщение «Внесён в CRM: <номер>, прибыль <сумма> ₽, <ссылка на карточку Notion>» (ссылка — URL созданной страницы Notion).
4. Цель дня (мгновенная проверка). День — с 09:00 до 09:00 по Новосибирску: дата дня `D=$(TZ=Asia/Novosibirsk date -d '-9 hours' +%F)`, начало — `${D}T09:00:00+07:00`. Посчитай строки базы «Тендеры» с временем создания (createdTime) не раньше начала дня. Цель — число из `/home/box/sysadmin/state/daily_goal` (файла нет — 10). Строк не меньше цели и метки `/home/box/sysadmin/state/goal_sent/<D>` нет — напиши главному боту Тэндер Мэн одно сообщение «Цель дня выполнена: N из X» с номерами тендеров и создай метку. Метка есть — Тэндер Мэну не пиши.

Числа бери только из файлов, ничего не выдумывай. Телефоны частных лиц не пиши. На Диске ничего не удаляй и не меняй файлы тендеров.

Кому отчитываться: пользователю в этот чат ничего не пиши. Все сообщения — только Тэндер Мэну (`<id Тэндер Мэна>`): по каждому перенесённому тендеру — номер, прибыль, ссылка на карточку; проблемные тендеры и уже бывшие в Notion — с причиной; ошибка 401 у rclone, Notion не читается или нет доступа — сразу. Новых тендеров не было — закончи молча.
