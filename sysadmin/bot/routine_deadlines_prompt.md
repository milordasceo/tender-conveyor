Рутина «Сроки заявок в CRM» (каждый день в 08:00 по Новосибирску): найди в базе Notion «Тендеры» строки, у которых истёк срок подачи заявок, и переведи их в «Просрочено» — в Notion и на Диске.

Устройство. База одна — «Тендеры» на странице «К рассмотрению». Свойство «Статус» (select, вариант «Просрочено», красный): пусто — тендер активный, «Просрочено» — срок подачи прошёл. Вид таблицы «Тендеры» показывает только строки со «Статус» пуст. Дочерняя страница «Просрочено» (⌛) на «К рассмотрению» — связанный вид (linked view) той же базы с фильтром «Статус = Просрочено», сортировка по «Подача до» по убыванию. «Перенос» в «Просрочено» = смена «Статус»; строки не удалять, не копировать, другую базу не заводить. «Дней до подачи» — формула, считается сама, её не заполнять и не трогать.

1. В Notion найди страницу «К рассмотрению», базу «Тендеры» и её источник данных (`search`, затем `fetch`). Прочитай все строки: Номер тендера, Товар, «Подача до», Статус (`query_data_sources`, SQL по колонкам `date:Подача до:start`, `Статус`). Активные — «Статус» пуст.
2. Для каждой активной строки посчитай сам (python), сколько осталось до «Подача до» от текущего момента; даты сравнивай в UTC (у «Подача до» есть часовой пояс). Пустое «Подача до» — ничего не меняй, выпиши номер в проблемы.
3. «Подача до» уже наступило (момент подачи ≤ сейчас) — по этой строке по порядку:
   - поставь «Статус» = «Просрочено» (`update_page`, только это свойство) и проверь `fetch`, что сохранилось;
   - перенеси папку: `rclone moveto 'gosplan:Госзакупки/CRM/<номер>' 'gosplan:Госзакупки/Просрочено/<номер>'`. Нет папки «Просрочено» — сначала `rclone mkdir 'gosplan:Госзакупки/Просрочено'`. В «Просрочено» папка с таким номером уже есть — не переноси и не затирай, это проблема. В «CRM» папки нет — тоже проблема (не ищи её по другим папкам);
   - проверь листингом: в «Просрочено» папка есть, в «CRM» её нет;
   - в теле карточки замени строку «Папка на Диске: Госзакупки / CRM / <номер>» на «Госзакупки / Просрочено / <номер>» (`update_page`, `update_content` по свежему `fetch`, остальной текст не трогай) и проверь `fetch`.
4. Сверка. `rclone lsf --dirs-only 'gosplan:Госзакупки/CRM/'` — номера папок должны совпасть с номерами активных строк (Статус пуст). Лишние папки или строки без папки — в проблемы, ничего не исправляй сам.
5. Повторный прогон безопасен: строки со «Статус» = «Просрочено» не трогай; если строка уже «Просрочено», а папка ещё в «CRM» (прошлый прогон оборвался) — доделай перенос и путь в карточке.

Чего не делать: не удалять строки, страницы и папки; не менять столбцы, фильтры и сортировку видов (кроме восстановления по правилам системного промта); не менять файлы тендеров; не трогать другие папки Диска.

Сообщения. Пользователю в этот чат ничего не пиши. Тэндер Мэну (`<id Тэндер Мэна>`) — одно сообщение, только если что-то ушло в «Просрочено» или что-то не удалось:
- «Просрочено: <номер> — <Товар>» по строке на каждый перенесённый тендер;
- «Не удалось: <номер> — <причина>» по каждой проблеме (пустое «Подача до», папки нет или уже есть в «Просрочено», расхождение сверки, ошибка Notion или rclone 401).
Ничего не просрочено и проблем нет — закончи молча.
