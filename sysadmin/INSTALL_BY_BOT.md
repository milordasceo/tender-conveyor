# Установка Сисадмина ботом

Для бота, который создаёт Сисадмина. Все значения — из `sysadmin/bot.yaml`. Кто такой Сисадмин и как работает — `sysadmin/README.md`.

Правила:

- шаги по порядку; следующий — только после контрольной точки (КТ);
- конфиг rclone (`~/.config/rclone/rclone.conf`) не читать, не показывать, не копировать, не менять;
- адреса почты, id страниц и баз Notion, id папок Диска нигде не писать — ни в чат, ни в файлы;
- правило владельца от 29.10.2026 для работающего Сисадмина: владельцу в свой чат он ничего не пишет; все сообщения (отчёты, вопросы, проблемы с тендером и доступом) — только Тэндер Мэну `<id Тэндер Мэна>`; после каждого тендера в Notion и «CRM» — сразу номер, прибыль, ссылка на карточку; цель дня (10) меняется только по явной команде владельца через Тэндер Мэна. Промты это уже содержат — вставлять дословно, подставив id;
- на Диске боевые «К рассмотрению» и «CRM» при установке только читаются; можно создать «CRM», если её нет (это не удаление и не перезапись); тестовая папка — только с разрешения;
- в Notion до шага 7 — только чтение, кроме создания страницы «К рассмотрению» и базы «Тендеры», если их нет;
- рутины при установке не создавать: шаг 9 «Рутины» выполняется на этапе «первичная настройка» (корневой `README.md`, шаг 7.3, пункт e) по команде Тэндер Мэна, с подтверждением владельца на карточке.

## 1. Прочитать манифест

Прочитать `sysadmin/bot.yaml`, `sysadmin/bot/prompt.md`, `sysadmin/bot/routine_check_folder_prompt.md`, `sysadmin/bot/routine_evening_report_prompt.md`, `sysadmin/README.md`, `sysadmin/examples/0151100007126000034/card.md`.

КТ: известны имя, промт, плейсхолдеры `<id Кузнеца>` и `<id Тэндер Мэна>`, две рутины (перенос каждые 30 минут, вечерний отчёт в 21:00, обе Asia/Novosibirsk), структура Notion (`notion_layout`), шаги владельца.

## 2. Создать бота

1. Создать бота: `bot.name` = Сисадмин, `bot.title`, `bot.description`.
2. Системный промт — весь файл `sysadmin/bot/prompt.md`; `<id Кузнеца>` заменить на id бота Кузнец, `<id Тэндер Мэна>` — на id бота Тэндер Мэн. Остальное без правок.
3. Подключить боту коннектор Notion (`connectors`). Рутины пока не создавать.

КТ: бот «Сисадмин» существует; в промте нет плейсхолдеров `<id …>` (`grep -c '<id ' ` по вставленному тексту — 0); последняя строка промта — ссылка на папку `sysadmin/`.

## 3. Запросить у владельца сразу всё

Одним сообщением, тексты — из `owner_steps`:

- `connect_notion` — показать карточку подключения Notion; владелец входит в своё рабочее пространство;
- `rclone_ready` — нужен rclone remote `gosplan:` с доступом к Drive (настраивает Кузнец);
- `test_folder` — разрешение на тестовую папку «Госзакупки/_проверка_сисадмина» (шаг 6);
- `test_card` — разрешение на тестовую страницу «_проверка_сисадмина» (шаг 7);
- `old_bot` — остановлен ли прежний Сисадмин.

Пока ждём ответа — шаги 4–5.

КТ: сообщение отправлено; ответы записаны по мере прихода.

## 6. Доступ к Диску и папка «CRM»

Нужен rclone remote `gosplan:` с доступом к Drive. Его настраивает Кузнец; Сисадмин его не создаёт.

```bash
rclone listremotes                                         # есть gosplan:
rclone lsf 'gosplan:Госзакупки'                            # К рассмотрению/ и CRM/
rclone lsf 'gosplan:Госзакупки' | grep -qx 'CRM/' || rclone mkdir 'gosplan:Госзакупки/CRM'   # нет CRM — создать
rclone lsf --dirs-only 'gosplan:Госзакупки/К рассмотрению' # номера тендеров или пусто
N=$(rclone lsf --dirs-only 'gosplan:Госзакупки/К рассмотрению' | head -1 | tr -d /)
[ -n "$N" ] && rclone copy "gosplan:Госзакупки/К рассмотрению/$N" "/tmp/sysadmin_check/$N" --include 'tender.*' --include 'цены.md' \
  && python3 /home/box/sysadmin/scripts/notion_card.py "/tmp/sysadmin_check/$N" --summary
TZ=Asia/Novosibirsk date -d '-9 hours' +%F                 # дата начала текущего дня цели
```

- нет `gosplan:` или 401 / `invalid_grant` — стоп, владельцу текст `owner_steps.rclone_ready`;
- нет «К рассмотрению» — не создавать, сообщить владельцу: папку наполняют предыдущие звенья;
- нет «CRM» — создать (`rclone mkdir`, команда выше). Сейчас она уже есть.

С разрешения `owner_steps.test_folder` — проверка переноса на тестовой папке (команды — `verification` в `bot.yaml`): образец в `_проверка_сисадмина/К рассмотрению/0151100007126000034`, `rclone moveto` в `_проверка_сисадмина/CRM/`, `rclone lsf -R`, затем `rclone purge 'gosplan:Госзакупки/_проверка_сисадмина'` — только эта тестовая папка. Разрешения нет — пропустить, в отчёте так и написать.

КТ: видны `К рассмотрению/` и `CRM/`; записано, сколько тендеров в «К рассмотрению»; сводка по одному живому тендеру напечатана без ошибок (или папка пуста); тестовый перенос прошёл и тестовая папка удалена (или пропущено); боевые папки не менялись (сверить `rclone lsf` до и после).

## 7. Notion

Нужно: владелец подключил Notion (`owner_steps.connect_notion`).

1. `search` «К рассмотрению». Есть страница — `fetch`, найти внутри базу «Тендеры», `fetch` базы, сверить свойства и раскладку с `notion_layout`.
2. Нет страницы — создать в корне рабочего пространства страницу «К рассмотрению», значок 📋. Нет базы — создать в ней базу «Тендеры» (свойство-заголовок «Номер тендера») и отобразить её inline: `notion-update-data-source` с `is_inline: true`. База есть, но на странице только ссылка «Тендеры» — тем же вызовом сделать inline.
3. Свойства: один вызов `update_data_source` со `statements` из `notion_layout.ddl` (только недостающие; у существующих select — перечислять все старые варианты).
4. Раскладка: **отдельный** вызов `update_data_source` с `page_layout`: `main` = title с `pinnedProperties` из `notion_layout.page_layout_header`, затем editor и discussions.
5. С разрешения `owner_steps.test_card`: создать в корне страницу «_проверка_сисадмина», тело — `examples/0151100007126000034/card.md`; `fetch`; затем убрать её в корзину. Разрешения нет — пропустить, в отчёте так и написать.

КТ: `fetch` базы «Тендеры» показывает 12 свойств в порядке `notion_layout.properties`, «Категория» с тремя вариантами (зелёный / оранжевый / красный), «Подача до» — дата; раскладка — шапка в порядке `page_layout_header`; `fetch` «К рассмотрению» показывает базу встроенной (inline), а не ссылкой; тестовая страница удалена (или шаг пропущен); строк в «Тендеры» не прибавилось.

## 9. Рутины

1. «Проверка папки «К рассмотрению»»: `CRON_TZ=Asia/Novosibirsk 0,30 * * * *` (каждые 30 минут, круглосуточно), время гибкое ±15 минут, промт — `sysadmin/bot/routine_check_folder_prompt.md`.
2. «Вечерний отчёт Тэндер Мэну»: `CRON_TZ=Asia/Novosibirsk 0 21 * * *` (каждый день в 21:00), время гибкое: раньше 0, позже до 10 минут, промт — `sysadmin/bot/routine_evening_report_prompt.md`.

Включать после `first_run.preconditions`. Прежний Сисадмин ещё работает — создать, но не включать, пока владелец не подтвердит остановку.
