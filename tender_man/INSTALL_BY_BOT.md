# Установка Тэндер Мэна ботом

Для пустого бота на новом аккаунте, который сам становится Тэндер Мэном (главой команды), а затем создаёт остальные звенья. Все значения — из `tender_man/bot.yaml`. Кто такой Тэндер Мэн — `tender_man/README.md`. Общий порядок bootstrap — корневой `README.md`.

Правила:

- шаги по порядку; следующий — только после контрольной точки (КТ);
- реальные agent id, адреса почты, id папок Drive и страниц Notion в репозиторий и отчёты не писать;
- конфиг rclone (`~/.config/rclone/rclone.conf`) не читать, не показывать, не копировать, не менять;
- рутины Тэндер Мэна создаёт владелец, не бот;
- в Notion и на Диске Тэндер Мэн только читает.

## 1. Прочитать манифест

```bash
rm -rf /tmp/tender-conveyor && git clone https://github.com/milordasceo/tender-conveyor.git /tmp/tender-conveyor
```

Прочитать `tender_man/bot.yaml`, `tender_man/bot/prompt.md`, `tender_man/prompts/morning_report_prompt.md`, `tender_man/prompts/evening_report_prompt.md`, `tender_man/README.md`, корневой `README.md` (раздел «Bootstrap»).

КТ: известны имя, промт, шесть плейсхолдеров (`bot.placeholders`), две рутины отчётов (план), коннектор Notion (необязателен), `verification`.

## 2. Стать Тэндер Мэном

1. Имя, заголовок, описание — из `bot`: `bot.name` = Тэндер Мэн, `bot.title`, `bot.description`.
2. Системный промт — весь файл `bot.prompt_file` (`tender_man/bot/prompt.md`), без правок по смыслу.
3. Плейсхолдеры звеньев (`<id Кузнеца>`, `<id Фатимы>`, `<id Черри Пикера>`, `<id Очкарика>`, `<id Сисадмина>`) пока оставить: этих ботов ещё нет. Заменить на шаге 7.
4. `<id Тэндер Мэна>` в своём промте — заменить своим agent id. Свой id записать: его подставляют во все звенья.
5. Рутины отчётов не создавать.

КТ: бот «Тэндер Мэн» с промтом из репозитория; последняя строка промта — ссылка на папку `tender_man/`; свой id известен.

## 3. Состояние бокса

Корневой `README.md`, шаг 0: свежий box (нет `gosplan:`) или общий (`rclone lsd gosplan:Госзакупки` отвечает). На общем box ничего не пересоздавать. Прежние боты конвейера — владелец останавливает их рутины до запуска новых.

КТ: записано: свежий или общий box; прежние боты остановлены или их нет.

## 4. Notion (необязательно)

`owner_steps.connect_notion`: показать владельцу карточку подключения Notion. После входа — `search` «К рассмотрению», `fetch` базы «Тендеры», только чтение. Нет коннектора — отчёты по сообщениям Сисадмина; это не блокирует установку.

КТ: Notion подключён и база «Тендеры» видна, или записано «без Notion».

## 5. Создать звенья

Строго в порядке корневого `README.md`, каждое — по его `INSTALL_BY_BOT.md`, в каждое подставить свой id вместо `<id Тэндер Мэна>`:

1. Кузнец — `kuznets/INSTALL_BY_BOT.md` (на свежем box создаёт rclone remote `gosplan:`);
2. загрузчик на Windows-ПК владельца — `fatima/stock_docs_fetcher/README.md`; ставит **владелец**, бот даёт инструкцию и ждёт `STATUS.bat`;
3. Фатима — `fatima/INSTALL_BY_BOT.md`;
4. Черри Пикер — `cherry_picker/INSTALL_BY_BOT.md`;
5. Очкарик — `ochkarik/INSTALL_BY_BOT.md`;
6. Сисадмин — `sysadmin/INSTALL_BY_BOT.md` (нужен Notion).

Рутины звеньев — по их INSTALL_BY_BOT, в Asia/Novosibirsk (`CRON_TZ=Asia/Novosibirsk …`).

КТ: пять ботов созданы; id каждого записан (только в промты, не в репозиторий).

## 6. Связать id

1. В свой промт — id всех пяти звеньев.
2. В промт Кузнеца — `<id Фатимы>`. `<id Скрипты и интеграции>` — такого бота в репозитории нет; плейсхолдер оставить, сообщить владельцу.
3. По всем вставленным промтам и промтам рутин: `rg -n "<id "` — пусто (кроме п. 2).

КТ: в промте Тэндер Мэна нет `<id `.

## 7. Проверка

Команды и ожидания — `verification` в `bot.yaml`:

1. `rg -n "<id "` по вставленному системному промту — пусто.
2. SendToAgent каждому из пяти звеньев: «Проверка связи от Тэндер Мэна, ответь «на связи» и одной строкой — что сейчас во входной папке» — пять ответов.
3. Notion (если подключён): база «Тендеры» найдена, видны «Номер тендера», «Прибыль», `createdTime`; ничего не менять.
4. Прогнать `prompts/morning_report_prompt.md` вручную, отправить владельцу с пометкой «тест» — три числа: ждут рассмотрения, добавлено вчера, самый выгодный.

КТ: все четыре пункта по `expect`. Ничего не записано ни на Диск, ни в Notion.

## 8. Рутины (создаёт владелец)

`owner_steps.routines`: дать владельцу тексты двух промтов и расписание:

- «Утренний отчёт владельцу» — `CRON_TZ=Asia/Novosibirsk 0 9 * * *`, гибко: раньше 0, позже до 15 минут, промт — `tender_man/prompts/morning_report_prompt.md`;
- «Вечерний отчёт владельцу» — `CRON_TZ=Asia/Novosibirsk 0 21 * * *`, так же, промт — `tender_man/prompts/evening_report_prompt.md`.

Часовой пояс — всегда Asia/Novosibirsk; часовой пояс бокса Grok Bot на расписание не влияет и для расчёта не используется.

КТ: владелец подтвердил, что обе рутины созданы.

## 9. Отчёт владельцу

Одно сообщение:

- Тэндер Мэн создан, промт вставлен; свежий или общий box;
- какие звенья созданы, какие плейсхолдеры остались (и почему);
- rclone `gosplan:` и раскладка Диска, загрузчик на Windows-ПК (работает / ждёт владельца);
- Notion: подключён / нет;
- результаты `verification` Тэндер Мэна и звеньев;
- рутины: какие созданы и включены, какие ждут владельца;
- что ждёт владельца (одним списком).
