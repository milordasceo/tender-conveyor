# Тэндер Мэн

Бот Grok Bot. Глава команды конвейера тендеров (госзакупки).

## Файлы папки

| файл | что |
|---|---|
| `bot.yaml` | манифест: бот, плейсхолдеры id, команда, рутины, шаги владельца, этап первичной настройки (`first_setup`), проверка |
| `INSTALL_BY_BOT.md` | пошагово: пустой бот → Тэндер Мэн → остальные звенья → первичная настройка, с контрольными точками |
| `bot/prompt.md` | только системный промт, вставлять целиком (заменить все `<id …>`) |
| `prompts/morning_report_prompt.md` | промт рутины «Утренний отчёт владельцу» |
| `prompts/evening_report_prompt.md` | промт рутины «Вечерний отчёт владельцу» |

## Роль

Единственный бот, который говорит с владельцем. Надзирает за пятью звеньями (Кузнец, Фатима, Черри Пикер, Очкарик, Сисадмин): принимает их отчёты, даёт команды, эскалирует нештатное владельцу, присылает утренний и вечерний отчёт по CRM. Работу конвейера сам **не делает**. Команда пишет только ему и друг другу, владельцу — никогда.

Не делает: не платит, не пишет письма и наружу, не трогает чужие папки, ничего не удаляет без команды владельца, не меняет порог прибыли (9 000 ₽) и цель дня (10) без явной команды владельца.

## Вход

Сообщения звеньев (SendToAgent); от Сисадмина — по каждому тендеру в CRM: номер, прибыль, ссылка. CRM — Notion, страница «К рассмотрению», база «Тендеры» (только чтение, если подключён коннектор). Диск — только чтение через rclone `gosplan:`, если нужно.

## Выход

Сообщения владельцу (отчёты, эскалации) и команды звеньям.

## Инструменты и скрипты

Скриптов нет. Нужны: SendToAgent (звенья), коннектор Notion (чтение CRM, необязателен), rclone remote `gosplan:` (только чтение, необязателен; настраивает Кузнец).

## Параметры и конфиг

Порог прибыли 9 000 ₽ (у Очкарика), цель дня 10 (у Сисадмина), день — 09:00–09:00 Asia/Novosibirsk. Меняются только по явной команде владельца; Тэндер Мэн передаёт её звену.

## Рутины

Создаёт Тэндер Мэн на этапе первичной настройки (пункт e), владелец одобряет каждую на карточке подтверждения. План:

| имя | cron | часовой пояс | промт |
|---|---|---|---|
| Утренний отчёт владельцу | `0 9 * * *` | Asia/Novosibirsk | `prompts/morning_report_prompt.md` |
| Вечерний отчёт владельцу | `0 21 * * *` | Asia/Novosibirsk | `prompts/evening_report_prompt.md` |

Утренний: сколько тендеров ждут рассмотрения в CRM, сколько добавлено вчера, самый выгодный тендер вчера. По запросу владельца — тот же отчёт сразу.

## Каналы связи

Владелец — отчёты, ответы, эскалации. Звенья — по id (`<id Кузнеца>`, `<id Фатимы>`, `<id Черри Пикера>`, `<id Очкарика>`, `<id Сисадмина>`). Свой id `<id Тэндер Мэна>` подставляется в промты звеньев.

## Секреты и как получить их заново

Нет. Notion — коннектор (подключает владелец), rclone — у Кузнеца.

## Установка с нуля

Пошагово — `INSTALL_BY_BOT.md` (пустой бот → Тэндер Мэн → звенья). Коротко:

1. Стать ботом «Тэндер Мэн»: системный промт — весь `bot/prompt.md`; `<id Тэндер Мэна>` — свой id; пять `<id …>` звеньев — после их создания.
2. Создать звенья в порядке корневого `README.md`, подставляя свой id вместо `<id Тэндер Мэна>`.
3. Этап «первичная настройка после создания ботов» (`first_setup`, корневой `README.md`, шаг 7):
   - каждое звено последним шагом установки присылает «Готов: <имя звена>, мой id <id>, от владельца нужно: <список>»; Тэндер Мэн ведёт чеклист и напоминает молчащим;
   - рассылает звеньям реальные id команды вместо `<id …>`, ждёт подтверждений;
   - проводит владельца по чеклисту, по одному пункту: вход rclone (Кузнец), загрузчик на Windows-ПК, Notion, роли на карточках, рутины с карточками подтверждения (включая две свои), тестовый прогон;
   - итоговая сводка владельцу; только после неё конвейер запущен.

## Проверка работы

Ping всем пяти звеньям — пять ответов; тестовый утренний отчёт с тремя числами. Ничего не пишется ни на Диск, ни в Notion.

## Известные проблемы

- Без коннектора Notion числа отчётов — по сообщениям Сисадмина; пропущенное сообщение = неточный счёт.
- На новом аккаунте не проверено.
