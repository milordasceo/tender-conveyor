# Установка Очкарика ботом

Для бота, который создаёт Очкарика. Все значения — из `ochkarik/bot.yaml`. Кто такой Очкарик и как работает — `ochkarik/README.md`.

Правила:

- шаги по порядку; следующий — только после контрольной точки (КТ);
- конфиг rclone (`~/.config/rclone/rclone.conf`) не читать, не показывать, не копировать, не менять;
- адрес Google-аккаунта нигде не писать. Называть его «аккаунт Google, владеющий папкой Госзакупки»;
- на Диске до шага 7 только чтение. Боевые «К расчёту», «К рассмотрению», «Нерентабельно» при установке не менять;
- рутину включать последней и только по слову владельца.

## 1. Прочитать манифест

Прочитать `ochkarik/bot.yaml`, `ochkarik/bot/prompt.md`, `ochkarik/bot/routine_prompt.md`, `ochkarik/README.md`.

КТ: известны имя, промт, рутина, раскладка Диска, шаги владельца. Плейсхолдер из `bot.placeholders`: `<id Тэндер Мэна>`.

## 2. Создать бота

1. Создать бота: `bot.name` = Очкарик, `bot.title`, `bot.description`.
2. Системный промт — весь файл `bot.prompt_file` (`ochkarik/bot/prompt.md`), без правок по смыслу; `<id Тэндер Мэна>` заменить на agent id Тэндер Мэна (бота ещё нет — оставить и заменить после его создания). Проверка: `rg -n "<id "` по вставленному тексту — пусто.
3. Рутину пока не создавать.

КТ: бот «Очкарик» существует; промт вставлен целиком (последняя строка — ссылка на папку `ochkarik/`).

## 3. Запросить у владельца сразу всё

Одним сообщением, тексты — из `owner_steps`:

- `rclone_ready` — нужен rclone remote `gosplan:` с доступом к Drive (настраивает Кузнец);
- `test_folder` — разрешение создать и удалить `Госзакупки/_проверка_очкарика` (шаг 7);
- `old_bot` — остановлен ли прежний Очкарик;
- `confirm_routine` — можно спросить сейчас, включать — на шаге 8.

Пока ждём ответа — шаги 4–5.

`/home/box/ochkarik/work` и `state` уже есть — не затирать.

КТ: `ls -d /home/box/ochkarik/work /home/box/ochkarik/state/в_работе` — обе папки есть; `ls /home/box/ochkarik/examples/0151100007126000034` — `tender.md`, `цены.md`; `test -x /home/box/ochkarik/scripts/calc.py && echo ok` — `ok`.

## 5. Зависимости

```bash
python3 --version                                # нужно >= 3.10
command -v rclone || (curl https://rclone.org/install.sh | sudo bash)
rclone version                                   # проверено на 1.75.2
python3 /home/box/ochkarik/scripts/calc.py --nmck 40785,40 --delivery 1500 --line А=25,00x380 --line Б=32,20x380
```

КТ: python3 >= 3.10; `rclone version` печатает версию; `calc.py` печатает «Прибыль варианта А (по ценам А): 25 317,59 ₽», «Прибыль варианта Б (по ценам Б): 22 991,99 ₽», «Вердикт: рентабельно».

## 6. Доступ к Диску (только чтение)

Нужен rclone remote `gosplan:` с доступом к Drive. На новом аккаунте его настраивает Кузнец; Очкарик его не создаёт.

```bash
rclone listremotes                                    # есть gosplan:
rclone lsf 'gosplan:Госзакупки'                       # К расчёту/ (К рассмотрению/, Нерентабельно/ — если есть)
rclone lsf --dirs-only 'gosplan:Госзакупки/К расчёту' # номера тендеров или пусто
```

- нет `gosplan:` или 401 / `invalid_grant` — стоп, владельцу текст `owner_steps.rclone_ready`;
- нет «К рассмотрению» или «Нерентабельно» — можно создать `rclone mkdir 'gosplan:Госзакупки/К рассмотрению'` и `rclone mkdir 'gosplan:Госзакупки/Нерентабельно'` (это не удаление и не перезапись), или оставить: Очкарик создаст их при первом переносе;
- нет «К расчёту» — не создавать: её наполняют предыдущие звенья. Сообщить владельцу.

КТ: `rclone lsf 'gosplan:Госзакупки'` показывает `К расчёту/`; записано, сколько тендеров сейчас в «К расчёту».

## 7. Проверка

Команды и ожидания — `verification` в `bot.yaml`:

1. Локальный расчёт и чтение Диска — уже сделано на шагах 5–6.
2. С разрешения владельца — тестовая папка `gosplan:Госзакупки/_проверка_очкарика`: образец тендера (`tender.md` без раздела расчёта и `цены.md`) в `_проверка_очкарика/К расчёту/0151100007126000034`, заливка `tender.md` с расчётом, `rclone moveto` в `_проверка_очкарика/К рассмотрению/`.
3. Уборка: `rclone purge 'gosplan:Госзакупки/_проверка_очкарика'` — только эта тестовая папка; `rm -rf /tmp/ochkarik_check`.

Разрешения на тестовую папку нет — пункты 2–3 пропустить, в отчёте так и написать.

КТ: `lsf -R` тестовой папки показывает `К рассмотрению/0151100007126000034/tender.md` и `цены.md`, в `К расчёту/` номера нет; `grep -c 'Прибыль варианта'` по залитому `tender.md` — 2; тестовая папка удалена; боевые папки не менялись (сверить `rclone lsf` до и после).

## 8. Рутина

1. Создать рутину из `routines`: «Расчёт: папка «К расчёту»», расписание `CRON_TZ=Asia/Novosibirsk */30 * * * *`, время гибкое: раньше до 15 минут, позже до 15 минут.
2. Промт — весь файл `ochkarik/bot/routine_prompt.md`, дословно.
3. Создать выключенной. Включить, когда владелец скажет (`owner_steps.confirm_routine`) и выполнены `first_run.preconditions`.

КТ: рутина есть, расписание `*/30 * * * *` Asia/Novosibirsk, гибкое ±15 минут; включена или на паузе — по слову владельца.

- бот «Очкарик» создан, промт вставлен;
- `/home/box/ochkarik` создан, `calc.py` на образце даёт 25 317,59 ₽ / 22 991,99 ₽; версии python, rclone;
- доступ `gosplan:` есть (аккаунт не называть); «К рассмотрению» и «Нерентабельно» найдены, созданы или будут созданы при первом переносе;
- сколько тендеров сейчас в «К расчёту»;
- проверка на тестовой папке: пройдена и папка удалена / пропущена без разрешения;
- рутина: имя, расписание, включена или на паузе.
