# tender-conveyor

Копия конвейера тендеров (госзакупки) для Grok Bot. Оригинал: https://github.com/milordasceo/gosplan-conveyor.

Каждое звено конвейера — отдельный бот. У звена своя папка. В папке всё, чтобы пересоздать бота: манифест `bot.yaml`, промты, рутины, скрипты, установка, проверка. Формат папки — `TEMPLATE_LINK.md`, схема манифеста — `SCHEMA.md`. Секретов в репозитории нет.

## Папки звеньев

| папка | звено |
|---|---|
| `kuznets/` | Кузнец — сканер gosplan.info (регион 54, 30–150 тыс. ₽, этап 1, 44-ФЗ и 223-ФЗ) → «Сток»; сопровождает загрузчик «Сток» → «Бланки» (`fatima/stock_docs_fetcher`) и общий remote `gosplan:` |
| `fatima/` | Фатима — документовед: разбор тендеров из «Бланков», загрузчик документов для windows-пк |
| `cherry_picker/` | Черри Пикер — ценоискатель: минимум две самые низкие цены по позициям тендеров из «Цены/<город>/В городе», цены.md, перенос в «К расчёту» |
| `ochkarik/` | Очкарик — просчёт рентабельности: прибыль вариантов цен из цены.md против НМЦК (доставка, налог УСН 15%), расчёт в tender.md, перенос в «К рассмотрению» (прибыль от 9 000 ₽) или «Нерентабельно» |
| `sysadmin/` | Сисадмин — перенос тендеров в Notion: карточки рентабельных тендеров из «К рассмотрению» в базу «Тендеры» (цена, прибыль, расходы, откуда забирать, куда везти, сроки) |

Другие звенья добавят свои папки сами.
