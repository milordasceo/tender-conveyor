# tender-conveyor

Конвейер тендеров (госзакупки, Новосибирск) для Grok Bot. Оригинал: https://github.com/milordasceo/gosplan-conveyor.

Этот файл — точка входа. Его читает пустой бот на новом аккаунте. Пустой бот становится Тэндер Мэном (глава команды) и создаёт остальных ботов по папкам этого репозитория.

## Что это

- Каждое звено — отдельный бот Grok Bot. У звена своя папка.
- В папке звена всё для пересоздания: `bot.yaml`, промты, рутины, скрипты, установка, проверка.
- Формат папки — [TEMPLATE_LINK.md](TEMPLATE_LINK.md). Схема манифеста — [SCHEMA.md](SCHEMA.md).
- Данные звеньев — на Google Drive в папке «Госзакупки». Доступ с бокса — rclone remote `gosplan:`.
- Звенья связаны папками Drive. Сообщения — только Тэндер Мэну через SendToAgent. Владельцу пишет только Тэндер Мэн.
- Секретов, адресов почты, id ботов и id папок Drive в репозитории нет.

## Схема конвейера

```
                              Тэндер Мэн  (глава: владелец ⇄ Тэндер Мэн ⇄ все звенья)
                                   │ отчёты, команды, эскалации
 ┌─────────────────────────────────┴───────────────────────────────────────────────────┐
 API gosplan.info → Кузнец → «Сток» → stock_docs_fetcher (Windows-ПК владельца) → «Бланки»
   → Фатима → «Цены/Новосибирск/<категория>» → Черри Пикер → «К расчёту»
   → Очкарик → «К рассмотрению» (прибыль от 9 000 ₽) | «Нерентабельно»
   → Сисадмин → Notion «Тендеры» (страница «К рассмотрению») + папка → «CRM»
```

## Bootstrap: пустой бот → Тэндер Мэн → звенья

Правила на весь bootstrap:

- шаги по порядку; следующий — после контрольной точки (КТ) текущего;
- `<id …>` в промтах заменять реальными agent id; бота ещё нет — оставить плейсхолдер, заменить после его создания;
- рутины каждого звена — последними, после его `verification`;
- секреты — только как секреты, не в чат, не в репозиторий, не в отчёты.

### 0. Состояние бокса

```bash
git clone https://github.com/milordasceo/tender-conveyor   # или git pull --rebase в существующей копии
rclone listremotes          # есть ли gosplan:
rclone lsd gosplan:Госзакупки
ls /home/box/gosplan        # следы прежнего Кузнеца
```

- **Свежий box**: нет rclone или нет `gosplan:`. Remote создаёт Кузнец (шаг 2), полностью по `kuznets/INSTALL_BY_BOT.md`.
- **Общий box**: `gosplan:` уже есть, `rclone lsd gosplan:Госзакупки` отвечает без 401/`invalid_grant`. Remote не пересоздавать, конфиг rclone не читать и не трогать. `/home/box/gosplan` и его `scripts/state`, `.env` не затирать. Кузнеца всё равно создать; шаги rclone и OAuth в его установке пропустить, если КТ шага 6 уже выполнена. 401/`invalid_grant` — повторный вход rclone по `kuznets/bot.yaml` → `owner_steps.rclone_authorize`.
- Есть прежние боты конвейера — владелец останавливает их рутины и фоновую выгрузку Кузнеца до запуска новых. Два Кузнеца на один «Сток» дают дубли. Два главы шлют отчёты дважды.

### 1. Стать Тэндер Мэном

1. Прочитать [tender_man/README.md](tender_man/README.md) и [tender_man/bot.yaml](tender_man/bot.yaml). INSTALL_BY_BOT у Тэндер Мэна нет.
2. Имя, заголовок, описание — из `bot`. Системный промт — весь `tender_man/bot/prompt.md`.
3. Плейсхолдеры звеньев пока оставить. Свой id записать: он `<id Тэндер Мэна>` во всех звеньях.
4. Рутины отчётов пока не создавать.

КТ: бот «Тэндер Мэн» с промтом из репозитория; свой id известен.

### 2. Кузнец (и rclone, если remote нет)

По [kuznets/INSTALL_BY_BOT.md](kuznets/INSTALL_BY_BOT.md). Подставить `<id Тэндер Мэна>`. `<id Фатимы>` — после шага 4.

- Свежий box: OAuth-клиент Google, `rclone config create gosplan …`, вход владельца через рабочий стол бокса, раскладка «Сток»/«Бланки».
- Общий box: проверить раскладку, ничего не пересоздавать.
- Реестр выгрузки — из `kuznets/state/`, не затирать существующий на боксе.

КТ: `rclone lsd gosplan:Госзакупки` показывает «Сток» и «Бланки»; проверка Кузнеца прошла; добор запущен.

### 3. Загрузчик на Windows-ПК владельца

Делает владелец на своём ПК с Google Drive for desktop: [fatima/stock_docs_fetcher/README.md](fatima/stock_docs_fetcher/README.md) → `INSTALL.bat`, `STATUS.bat`, `TEST.bat`. Бот даёт инструкцию и ждёт подтверждения.

КТ: `STATUS.bat` — загрузчик работает; папки из «Сток» уходят в «Бланки».

### 4. Фатима

По [fatima/INSTALL_BY_BOT.md](fatima/INSTALL_BY_BOT.md).

- **Плейсхолдеры**: в `fatima/bot.yaml` `placeholders: {}`, но `fatima/bot/prompt.md` и `fatima/bot/routine_prompt.md` содержат `<id Тэндер Мэна>`. Заменить в обоих файлах. Проверка: `rg -n "<id "` по вставленным текстам — пусто.
- rclone Фатима не создаёт; нет `gosplan:` — вернуться к шагу 2.

### 5. Черри Пикер

По [cherry_picker/INSTALL_BY_BOT.md](cherry_picker/INSTALL_BY_BOT.md). Плейсхолдеры: `<id Тэндер Мэна>`, `<id Кузнеца>` — в промте и в промте рутины.

### 6. Очкарик

По [ochkarik/INSTALL_BY_BOT.md](ochkarik/INSTALL_BY_BOT.md). Плейсхолдер: `<id Тэндер Мэна>`.

### 7. Сисадмин

По [sysadmin/INSTALL_BY_BOT.md](sysadmin/INSTALL_BY_BOT.md). Плейсхолдеры: `<id Тэндер Мэна>`, `<id Кузнеца>`. Нужен коннектор Notion (подключает владелец) и папка «CRM».

### 8. Связать id

1. В промт Тэндер Мэна — id всех пяти звеньев (`<id Кузнеца>`, `<id Фатимы>`, `<id Черри Пикера>`, `<id Очкарика>`, `<id Сисадмина>`).
2. В промт Кузнеца — `<id Фатимы>`. `<id Скрипты и интеграции>` — бота с такой папкой в репозитории нет; оставить плейсхолдер и сообщить владельцу.
3. Во всех вставленных промтах и промтах рутин `rg -n "<id "` — пусто (кроме п. 2).

КТ: `tender_man/bot.yaml` → `verification`: пять ответов на ping, тестовый утренний отчёт с тремя числами.

### 9. Рутины

Единый часовой пояс рутин — **Asia/Novosibirsk** (`CRON_TZ=Asia/Novosibirsk …`), как у Тэндер Мэна, Сисадмина и счётчика Фатимы.

| звено | рутина | в манифесте |
|---|---|---|
| Тэндер Мэн | отчёты 09:00, 21:00 | Asia/Novosibirsk; создаёт владелец |
| Сисадмин | проверка «К рассмотрению» :00/:30; вечерний отчёт 21:00 | Asia/Novosibirsk |
| Кузнец | утренний скан 07:00; почасовой добор | пояс бокса (`date`) |
| Фатима | будни 08:00–19:30 каждые 30 мин | Europe/Berlin |
| Черри Пикер | :00/:30 | Europe/Berlin |
| Очкарик | каждые 30 мин | Europe/Madrid |

У Кузнеца, Фатимы, Черри Пикера, Очкарика пояс в манифесте другой. Перед созданием их рутин — пересчитать время в Asia/Novosibirsk и подтвердить у владельца (`owner_steps.confirm_schedule` / `confirm_routine`). Для рутин каждые 30 минут и каждый час пояс на расписание не влияет.

### 10. Отчёт владельцу

Одно сообщение от Тэндер Мэна: созданные боты, свежий или общий box, rclone и Drive-раскладка, загрузчик, Notion, результаты проверок, включённые рутины, оставшиеся плейсхолдеры, что ждёт владельца.

## Что не коммитить

- секреты: `.env`, `rclone.conf`, `client_secret*.json`, `*.token`, OAuth client id/secret, `GOSPLAN_API_KEY`;
- реальные agent id, адреса почты, id папок Drive, id страниц Notion;
- рабочее состояние: `state/`, `logs/`, `tenders/`, `*.lock`, `*.slot`, `__pycache__/` (см. `.gitignore`); исключение — перенесённый реестр `kuznets/state/`;
- локальный `config.json` загрузчика (пути Windows-ПК владельца).

Правки — только в своей папке звена. Чужие папки не трогать.

## Чеклист миграции

- [ ] прежние боты остановлены: рутины, фоновая выгрузка Кузнеца, прежний Тэндер Мэн;
- [ ] `gosplan:` работает (свежий box — создан Кузнецом; общий — проверен, не пересоздан);
- [ ] реестр выгрузки перенесён, боевой не затёрт;
- [ ] загрузчик на Windows-ПК работает;
- [ ] шесть ботов созданы, промты из репозитория;
- [ ] `rg -n "<id "` пусто во всех промтах (кроме `<id Скрипты и интеграции>`); у Фатимы — оба файла;
- [ ] Notion подключён (Сисадмин — обязательно, Тэндер Мэн — по желанию);
- [ ] `verification` каждого звена пройден;
- [ ] рутины созданы последними, в Asia/Novosibirsk, время подтвердил владелец.
