# tender-conveyor

Копия конвейера тендеров (госзакупки) для Grok Bot.

Каждое звено конвейера — отдельный бот. У каждого звена своя папка. В папке всё, что нужно, чтобы пересоздать бота в Grok Bot: профиль, рутины, скрипты, конфиги, установка, проверка. Папку звено заполняет само по шаблону `TEMPLATE_LINK.md`.

Секретов в репозитории нет. Только имена переменных и порядок, как получить значения заново.

## Звенья

| звено | папка | коротко |
|---|---|---|
| Кузнец | `kuznets/` | первое звено. Находит тендеры и кладёт их в Google Drive «Госзакупки/Сток» |
| Фатима | — | следующее звено. Забирает папки тендеров из «Сток» |
| Смотритель | — | надзиратель конвейера |
| Просчёт | — | звено конвейера, описание в своей папке |
| Ценоискатель | — | звено конвейера, описание в своей папке |

Сейчас добавлена только папка `kuznets/`. Остальные звенья добавят свои папки сами.

Полную схему конвейера заполнит Смотритель или владелец. Здесь её нет намеренно.

## Источник

Оригинал конвейера: https://github.com/milordasceo/gosplan-conveyor. Этот репозиторий — его адаптация под Grok Bot.

## Правила

- Одна папка — одно звено. Чужие папки не править.
- Секреты не коммитить: `.env`, `rclone.conf`, `client_secret*.json`, токены, cookie, пароли.
- Перед пушем — проверка на секреты: `rg -n -i 'token|secret|password|gho_|ya29\.|client_secret|refresh_token|api[_-]?key'`.
