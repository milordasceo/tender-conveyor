Работа (до 3 тендеров за прогон, обязательно через фонового исполнителя): бери тендеры только из папки «<город>/В городе». Папки «Загород» и «С ограничениями» не трогать — только по явной команде владельца или главного бота Тэндер Мэн (id <id Тэндер Мэна>). Тендеры в «В городе», где уже лежит «цены.md» (задержанные по правилу «минимум 2 цены»), повторно не брать. Папки в «Госзакупки/К расчёту» не трогать. По каждому тендеру:
1. Прочитай tender.json / tender.md (при необходимости описание объекта закупки): точные названия позиций, характеристики, количества, единицы; есть ли явное разрешение аналога.
2. По каждой позиции найди в интернете в пределах города тендера самые низкие цены, минимум 2 источника с реальными открытыми страницами. Ищи строго по названию и характеристикам; аналог — только если документы явно разрешают, и тогда помечай это. Источники-подсказки владельца: nsk.pulscen.ru, nsk.blizko.ru, lenta.com/catalog, Avito (Новосибирск), Wildberries — плюс любые другие. Браузер для них — только запасной вариант, если других источников цен мало. Цены не придумывать; не нашёл — пиши «не нашёл».
3. Создай в папке тендера короткий, удобный для бота файл «цены.md»: по каждой позиции только название (с ключевыми характеристиками и количеством), «Цена 1» за единицу ТЗ + где купить (поставщик, адрес — обязательно, телефон если есть, ссылка), «Цена 2» так же, и при необходимости одна строка про фасовку. Внизу дата проверки. Никаких итогов против НМЦК, маржи, справочных таблиц и длинных оговорок.
   У каждой цены сразу после строк адреса и телефона — отдельная строка ровно так: `- 2ГИС: <ссылка>`. Ссылка — карточка здания `https://2gis.ru/<город латиницей>/geo/<id здания>`, без `?stat=` (пример: https://2gis.ru/novosibirsk/geo/141373143574119). id здания (без ключа API): адрес сократить до города, улицы и дома (без компании, индекса, телефона, офиса, этажа); один GET на `https://2gis.ru/<город>/search/<адрес в URL-кодировке>` с обычным браузерным User-Agent (без него 2ГИС уводит на /museum), пауза ~1 с между адресами; в HTML найти JSON `initialState` → `data.entity.profile` и брать id, только если найдено ровно одно здание и номер дома совпал. Иначе (не совпало, 404, нет сети) — ссылка `https://2gis.ru/<город>/search/<адрес>`.
3а. Правило «минимум 2 цены»: если хотя бы по одной позиции нет двух найденных цен (есть «не нашёл»), папку НЕ переносить и счётчик НЕ менять. Если прошлый прогон ещё обрабатывает тендеры — не бери их повторно.
