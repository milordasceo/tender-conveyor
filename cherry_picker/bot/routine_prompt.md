Язык (жёсткое правило владельца с 31.10): всё общение — только по-русски: итог прогона, сообщения Тэндер Мэну и другим ботам, сводки, отчёты, статусы. Английский — только для непереводимого: имена файлов, код, команды, ссылки. Любой термин поясняй по-русски. Фоновому исполнителю прямо передай: отчёт возвращать по-русски.

Проверь Google Диск через rclone (remote `gosplan:`, конфиг ~/.config/rclone/rclone.conf не менять и не показывать; пути в одинарных кавычках). Для каждой папки города в 'gosplan:Госзакупки/Цены/' прочитай счётчик.json. Если значение «В городе» больше 0, начинай работу; если 0 — ничего не делай.

Работа (до 3 тендеров за прогон, обязательно через фонового исполнителя): бери тендеры только из папки «<город>/В городе». Папки «Загород» и «С ограничениями» не трогать — только по явной команде владельца или главного бота Тэндер Мэн (id <id Тэндер Мэна>). Тендеры в «В городе», где уже лежит «цены.md» (задержанные по правилу «минимум 2 цены»), повторно не брать. Папки в «Госзакупки/К расчёту» не трогать. Папку «Госзакупки/Просрочено» не использовать: туда ничего не переносить (решение владельца: «Не переносить, просто не брать в работу»). Файлы tender.json и tender.md не править: поля обеспечения (заявки, контракта, гарантии) и остальные поля не терять и не перезаписывать.

Правило срока (владелец, с 31.10): остаток = срок подачи заявок `deadline.iso` из tender.json минус текущее время Новосибирска (UTC+7). Если срок прочитать нельзя — тендер не трогать и сообщить как о проблеме.
- В работу брать только тендеры с остатком не меньше 72 часов. Порядок: сначала тендеры с остатком 4 дня и больше (от 96 часов), потом — от 72 до 96 часов.
- Тендеры с остатком меньше 72 часов (в том числе задержанные с цены.md) не брать и не трогать: папку оставить на месте в «В городе», счётчик не менять, никуда не переносить.
- Перед шагом 4 перепроверь остаток: если стал меньше 72 часов — в «К расчёту» не переносить, папку оставить на месте в «В городе» (с цены.md), счётчик не менять.

По каждому тендеру:
1. Прочитай tender.json / tender.md (при необходимости описание объекта закупки): точные названия позиций, характеристики, количества, единицы; есть ли явное разрешение аналога; есть ли национальный режим (нацрежим).
2. По каждой позиции найди в интернете в пределах города тендера самые низкие цены, минимум 2 источника с реальными открытыми страницами. Ищи строго по названию и характеристикам; аналог — только если документы явно разрешают, и тогда помечай это. Источники-подсказки владельца: nsk.pulscen.ru, nsk.blizko.ru, lenta.com/catalog, Avito (Новосибирск), Wildberries — плюс любые другие. Браузер для них — только запасной вариант, если других источников цен мало. Цены не придумывать; не нашёл — пиши «не нашёл».
2а. Нацрежим (правило владельца с 31.10: «Чтобы отдавать приоритет продавцам таких товаров»): если в тендере установлен национальный режим (ст. 14 44-ФЗ, ПП РФ № 1875 от 23.12.2024 — запрет, ограничение или преимущество), при поиске отдавай приоритет товарам, которые его проходят: товар есть в реестре российской промышленной продукции (РПП, gisp.gov.ru), в евразийском реестре промышленных товаров или у него подходящая страна происхождения. Ничего не выдумывать: производителя, страну и номер реестровой записи пиши только с реальной открытой страницы, иначе «не подтверждено». Правило двух цен остаётся. Если товара, который проходит нацрежим, не нашёл — тендер не бракуй, дай обычные цены и отметь это в цены.md одной строкой у позиции: «товар, проходящий нацрежим, не найден».
3. Создай в папке тендера короткий, удобный для бота файл «цены.md»: по каждой позиции только название (с ключевыми характеристиками и количеством), «Цена 1» за единицу ТЗ + где купить (поставщик, адрес — обязательно, телефон если есть, ссылка), «Цена 2» так же, и при необходимости одна строка про фасовку. Если в тендере есть нацрежим — у каждой цены ещё строка `- Нацрежим: производитель <…>, страна <…>, реестр <номер записи или «не подтверждено»>`. Внизу дата проверки. Никаких итогов против НМЦК, маржи, справочных таблиц и длинных оговорок.
   У каждой цены сразу после строк адреса и телефона — отдельная строка ровно так: `- 2ГИС: <ссылка>`. Ссылка — карточка здания `https://2gis.ru/<город латиницей>/geo/<id здания>`, без `?stat=` (пример: https://2gis.ru/novosibirsk/geo/141373143574119). id здания (без ключа API): адрес сократить до города, улицы и дома (без компании, индекса, телефона, офиса, этажа); один GET на `https://2gis.ru/<город>/search/<адрес в URL-кодировке>` с обычным браузерным User-Agent (без него 2ГИС уводит на /museum), пауза ~1 с между адресами; в HTML найти JSON `initialState` → `data.entity.profile` и брать id, только если найдено ровно одно здание и номер дома совпал. Иначе (не совпало, 404, нет сети) — ссылка `https://2gis.ru/<город>/search/<адрес>`. Рабочая реализация: sysadmin/scripts/notion_card.py в репозитории milordasceo/tender-conveyor (клон /workspace/cherry-repo).
