# Установка Черри Пикера ботом

Для бота, который создаёт Черри Пикера. Все значения — из `cherry_picker/bot.yaml`. Кто такой Черри Пикер и как работает — `cherry_picker/README.md`.

Правила:

- шаги по порядку; следующий — только после контрольной точки (КТ);
- конфиг rclone (`~/.config/rclone/rclone.conf`) не читать, не показывать, не копировать, не менять;
- адрес Google-аккаунта нигде не писать. Называть его «аккаунт Google, владеющий папкой Госзакупки»;
- на Диске до шага 7 только чтение. Боевые «Цены», «К расчёту» и счётчики при установке не менять;
- рутину включать последней и только по слову владельца;
- правило владельца от 29.10.2026 для работающего Черри Пикера: владельцу в чат он ничего не пишет; все отчёты, вопросы и проблемы — одним коротким сообщением Тэндер Мэну `<id Тэндер Мэна>` через SendToAgent, при 401 / `invalid_grant` ещё Кузнецу `<id Кузнеца>`. Промты это уже содержат — вставлять дословно, подставив id.

## 1. Прочитать манифест

Прочитать `cherry_picker/bot.yaml`, `cherry_picker/bot/prompt.md`, `cherry_picker/bot/routine_prompt.md`, `cherry_picker/README.md`.

КТ: известны имя, промт, рутина, плейсхолдеры, раскладка Диска, шаги владельца.

## 2. Создать бота

1. Создать бота: `bot.name` = Черри Пикер, `bot.title`, `bot.description`.
2. Системный промт — весь файл `bot.prompt_file` (`cherry_picker/bot/prompt.md`).
3. Заменить плейсхолдеры из `bot.placeholders`: `<id Тэндер Мэна>`, `<id Кузнеца>` — на agent id этих ботов (Тэндер Мэн — глава команды). Бота ещё нет — оставить плейсхолдер, записать в отчёт, заменить после его создания.
4. Рутину пока не создавать.

КТ: бот «Черри Пикер» существует, промт вставлен целиком; в промте нет id старой установки.

## 3. Запросить у владельца сразу всё

Одним сообщением, тексты — из `owner_steps`:

- `rclone_ready` — нужен rclone remote `gosplan:` с доступом к Drive (настраивает Кузнец);
- `test_folder` — разрешение создать и удалить `Госзакупки/_проверка_черри` (шаг 7);
- `old_bot` — остановлен ли прежний Черри Пикер;
- `confirm_routine` — можно спросить сейчас, включать — на шаге 8.

Пока ждём ответа — шаги 4–5.

КТ: python3 >= 3.10, `rclone version` печатает версию.

## 6. Доступ к Диску (только чтение)

Нужен rclone remote `gosplan:` с доступом к Drive. На новом аккаунте его настраивает Кузнец; Черри Пикер его не создаёт.

```bash
rclone listremotes                               # есть gosplan:
rclone lsf 'gosplan:Госзакупки'                  # Цены/ и К расчёту/
rclone lsf --dirs-only 'gosplan:Госзакупки/Цены' # города, например Новосибирск/
rclone lsf 'gosplan:Госзакупки/Цены/Новосибирск' # В городе/, Загород/, С ограничениями/, счётчик.json
rclone cat 'gosplan:Госзакупки/Цены/Новосибирск/счётчик.json'
```

- нет `gosplan:` или 401 / `invalid_grant` — стоп, владельцу текст `owner_steps.rclone_ready`;
- нет «К расчёту» — создать `rclone mkdir 'gosplan:Госзакупки/К расчёту'` (это не удаление и не перезапись);
- нет «Цены» или папок города — не создавать: их ведёт Фатима. Сообщить владельцу;
- нет `счётчик.json` — не создавать: его создаёт Фатима при первом переносе.

КТ: `rclone lsf 'gosplan:Госзакупки'` показывает `Цены/` и `К расчёту/`; счётчик читается и это JSON `{"В городе": N, "Загород": N, "С ограничениями": N, "обновлено": "YYYY-MM-DD HH:MM"}` (или его пока нет — записать в отчёт).

2. С разрешения владельца — тестовая папка `gosplan:Госзакупки/_проверка_черри`: образец `цены.md` и тестовый счётчик («В городе»: 1) в `_проверка_черри/Цены/Тест/`, `rclone moveto` папки тендера в `_проверка_черри/К расчёту/`, −1 в тестовом счётчике.
3. Уборка: `rclone purge 'gosplan:Госзакупки/_проверка_черри'` — только эта тестовая папка; `rm -rf /tmp/cherry_check`.

Разрешения на тестовую папку нет — пункты 2–3 пропустить, в отчёте так и написать.

КТ: `lsf -R` тестовой папки показывает `К расчёту/0151100007126000034/цены.md`, тестовый счётчик — «В городе»: 0 и «обновлено» по Новосибирску; тестовая папка удалена; боевые «Цены», «К расчёту» и счётчики не менялись (сверить `rclone lsf` и `rclone cat` до и после).

## 8. Рутина

1. Создать рутину из `routines`: «Цены: проверка папки «В городе»», расписание `CRON_TZ=Asia/Novosibirsk 0,30 * * * *`, время гибкое: раньше до 15 минут, позже до 15 минут.
2. Промт — весь файл `cherry_picker/bot/routine_prompt.md`, дословно; заменить в нём `<id Тэндер Мэна>`, `<id Кузнеца>` на agent id.
3. Создать выключенной. Включить, когда владелец скажет (`owner_steps.confirm_routine`) и выполнены `first_run.preconditions`.

КТ: рутина есть, расписание `0,30 * * * *` Asia/Novosibirsk, гибкое ±15 минут; включена или на паузе — по слову владельца.
