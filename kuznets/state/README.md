# реестр выгрузки кузнеца

перенесённое состояние сканера с прежнего компьютера.

- `export_00cd167b09dc.json` — реестр: `tenders` уже выгружены в «Госзакупки/Сток», `pending` ждут выгрузки. только публичные номера и данные тендеров.

при установке: скопировать `export_*.json` в state_dir сканера (`/home/box/gosplan/scripts/state/`) до первого запуска. имя файла зависит от конфига и remote; не переименовывать. первый запуск на новом компьютере догрузит очередь и только потом начнёт новый поиск.

если файл не положить — сканер начнёт с пустого реестра и выгрузит заново тендеры, которые фатима уже унесла из «стока».
