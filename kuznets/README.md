# Кузнец

Первое звено конвейера тендеров. Бот Grok Bot.

Файлы папки:

- `bot/profile.md` — профиль бота (имя, заголовок, описание) и уточнения владельца;
- `bot/routine.md` — ежедневная рутина: расписание и полный текст промта;
- `scripts/` — сканер gosplan.info, библиотека, конфиги, README сканера;
- `SETUP.md` — установка с нуля на новом боксе и проверка;
- `FORMAT.md` — формат папки тендера, которую получает Фатима;
- `examples/` — реальные папки тендеров из пробной выгрузки (44-ФЗ и 223-ФЗ).

## Роль

Кузнец находит новые тендеры и кладёт их в Google Drive «Госзакупки/Сток». Раз в сутки, утренней рутиной. Работает на своём боксе Grok Bot, не на компьютере владельца.

Второе дело — сопровождать сканер и инструменты конвейера.

Кузнец не делает:

- не скачивает документы тендеров (это делает Фатима своим скриптом);
- не разбирает тендеры;
- не пишет заявки и сопроводительные документы;
- не отправляет письма, посты, платежи;
- не трогает данные конвейера руками — только скриптами.

## Вход

- API gosplan.info (бесплатный, тестовый сервер `https://v2test.gosplan.info`, без ключа);
- конфиг `scripts/config.novosibirsk.yaml`;
- реестр выгруженных номеров в `state_dir` на боксе.

## Выход

Каждый новый тендер — отдельная папка в «Госзакупки/Сток». Имя папки — номер тендера. Внутри `tender.md` и `tender.json`: данные тендера, ссылки на тендер и на все документы. Формат — `FORMAT.md`.

Тендеры с поставкой вне города тоже выгружаются. Они только помечаются (`город: вне города`).

Сток забирает Фатима.

## Ежедневный цикл

1. Рутина утром запускает сканер (`bot/routine.md`).
2. Сканер ищет тендеры по фильтрам конфига.
3. Новые номера встают в очередь `pending`.
4. Каждый номер из очереди: запрос детали в API, сборка `tender.md` + `tender.json`, `rclone copy` в `gosplan:Госзакупки/Сток/<номер>`.
5. Номер попадает в реестр только после успешной загрузки.
6. Код выхода: `0` — всё выгружено, `3` — очередь не пуста, другой — ошибка.
7. Кузнец читает `run_report.json` и пишет Смотрителю одно короткое сообщение, если есть результат или проблема. Нечего сообщить — молчит.

## Первый запуск и очередь

- Первый запуск берёт ВСЕ тендеры, которые сейчас подходят под фильтры. `since: auto` при пустом реестре = без фильтра по дате публикации.
- Пока очередь `pending` не пуста, нового поиска нет. Каждый запуск добирает очередь. Код выхода `3`.
- Очередь пуста — в реестре ставится `last_completed_at`.
- Дальше ежедневные запуски берут только тендеры с даты последнего завершённого прогона минус 1 день (`Europe/Moscow`).

## Дедупликация

- Реестр выгруженных номеров лежит в `state_dir` на боксе (по умолчанию `scripts/state`, файл `export_<sha1 строки remote>[:12].json`).
- Реестр не в «Сток»: Фатима уносит папки из «Сток», по наличию папок дубли не отследить.
- Номер в реестре только после кода 0 у `rclone copy`. Сбой загрузки оставляет номер в очереди.
- Перед выгрузкой сканер один раз читает список папок в «Сток» (`rclone lsf`). Папка уже есть — номер записывается в реестр без копирования.
- Итог: повторный прогон не создаёт дублей.

## Лимит API

- Не больше 10 запросов в минуту. Базовый интервал 10 с между запросами.
- HTTP 429: интервал ×1.5 (потолок 20 с) до конца прогона, пауза по `Retry-After`, до 4 повторов.
- Слот общий для всех процессов: файл `gosplan_api.slot` в `state_dir`, блокировка `flock`.

## Параметры

Текущие (`scripts/config.novosibirsk.yaml`):

| параметр | значение | ключ конфига | флаг CLI |
|---|---|---|---|
| регион | 54 (Новосибирская область) | `filters.regions` | `--region` |
| город поставки | Новосибирск (только пометка) | `filters.delivery_cities` | — |
| НМЦК от | 30 000 ₽ | `filters.min_budget` | `--price-min` |
| НМЦК до | 150 000 ₽ | `filters.max_budget` | `--price-max` |
| этап | 1 (подача заявок) | `filters.stage` | `--stage` |
| виды | запрос котировок, аукцион | `filters.purchase_types` / `filters.kinds` | `--kind` (`auction`, `zk`, `ok`, `zp`, `ep`) |
| законы | 44-ФЗ, 223-ФЗ | `sources` / `filters.types` | `--types` |
| окончание этапа | не задано | `filters.deadline_from`, `filters.deadline_to` | `--deadline-from`, `--deadline-to` |
| дата публикации | `auto` | `filters.since` | `--since` |

Приоритет: флаг CLI, затем конфиг, затем умолчание.

## Как менять параметры

- Параметры меняет только Кузнец.
- Основание: команда владельца или договорённость со Смотрителем.
- Меняется yaml-конфиг, не промт рутины. После правки — пробный прогон `--dry-run`, затем отчёт Смотрителю: что было, что стало.
- Другие звенья параметры не правят. Им нужно другое — пишут Смотрителю.

## Сопровождение кода

- Кузнец отвечает за сканер и инструменты.
- Правки кода Кузнец заказывает боту «Скрипты и интеграции». Тот работает через Grok Build CLI с `--reasoning-effort medium`, чтобы беречь лимиты.
- Формат заказа: «нужно: …; на входе: …; на выходе: …; приёмочный критерий: …».
- Кузнец принимает работу только после живого прогона.

## Каналы связи

- Итоги и проблемы — одним сообщением Смотрителю (бот-надзиратель).
- Срочное для владельца — в том же сообщении строкой «владельцу:».
- Владельцу напрямую не пишет.
- Нет нового — молчит.

## Секреты

Значений в репозитории нет. Как получить — `SETUP.md`.

| что | где | зачем |
|---|---|---|
| OAuth-клиент Google (client_id, client_secret) | `rclone.conf` на боксе | доступ rclone к Drive |
| токен rclone | `rclone.conf` на боксе | авторизация Drive |
| ключ gosplan (`api_key`) | поле `api_key` в yaml-конфиге на боксе (сканер читает ключ только оттуда; `GOSPLAN_API_KEY` в `.env` — справочно) | только для прод-сервера gosplan |

## Открытые вопросы

- Время рутины не утверждено. Рутина не создана, владелец задаст время (`bot/routine.md`).
- Прод-ключ gosplan не получен. Работа идёт на тестовом сервере.
- OAuth-приложение Google в режиме Testing. Токен живёт 7 дней. Нужны homepage и privacy policy URL и публикация приложения.
- Не проверено, режет ли умолчание API `published_forpast=1m` первый полный прогон.
- Полная схема конвейера — за Смотрителем и владельцем.

## Известные проблемы

- Тестовый API gosplan часто отвечает 429. Полный первый прогон (~80 тендеров) шёл ~45 минут. Прод-ключ может помочь.
- Умолчание API `published_forpast=1m` может ограничить первый полный прогон. Не проверено.
- Общий client_id rclone для Google выводится из оборота. Нужен свой OAuth-клиент. Свой клиент есть, но приложение в режиме Testing: токены истекают через 7 дней, пока не заданы homepage/privacy URL и приложение не опубликовано.
- zakupki.gov.ru с бокса недоступен (гео). Для выгрузки это не мешает: в папку пишутся только ссылки.
