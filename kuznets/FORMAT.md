# Формат папки тендера

Что Кузнец кладёт в «Госзакупки/Сток» и что забирает Фатима. Сверено с кодом `scripts/gosplan_scanner.py` (функции сборки `tender.md` / `tender.json`) и с живой выгрузкой 2026-10-29.

## Папка

- путь: `Госзакупки/Сток/<номер>/`
- имя папки = номер тендера (`purchase_number`): 19 цифр для 44-ФЗ, 11 цифр для 223-ФЗ;
- внутри ровно два файла: `tender.md`, `tender.json`;
- документы тендера не скачиваются, в файлах только ссылки;
- в «Сток» только папки номеров. Реестр и служебные файлы лежат на боксе Кузнеца.

## Поля

| поле в `tender.md` | ключ в `tender.json` | смысл |
|---|---|---|
| заголовок `# <номер>` | `number` | номер тендера |
| закон | `law` | `44-ФЗ` или `223-ФЗ` |
| тип закупки | `purchase_type`, `purchase_type_name` | код типа и русское имя; в md — `код (имя)`; неизвестный код пишется как есть |
| предмет | `subject` | предмет закупки |
| нмцк | `initial_price`, `currency` | начальная цена и валюта |
| регион | `region` | код региона KLADR |
| место поставки | `delivery_places` | тексты места поставки; в md через `; ` |
| город | `city_check` | `в городе`, `вне города`, `нет данных` (`не проверялось`, если город в конфиге не задан); в md с городом в скобках |
| этап | `stage` | 1 — подача заявок |
| окончание этапа | `stage_end` | дата и время окончания этапа (ISO) |
| опубликовано | `published_at` | дата публикации (ISO) |
| заказчики | `customers` | ИНН заказчиков, список |
| поиск на zakupki | `zakupki_search` | поиск номера в ЕИС |
| карточка zakupki | `zakupki_card` | прямая карточка в ЕИС, если тип известен |
| api gosplan | `gosplan` | URL детали в API gosplan.info (HTML-карточки у gosplan нет) |
| `## Документы` | `documents` | нумерованный список: `N. [имя](url) — описание`; в json `[{name, description, url, size}]` |

Пустое значение в `tender.md` — `—`. Нет документов — строка `нет документов`. Заказчики в md через `, `.

Документы: вложения извещения (44-ФЗ `attachmentsInfo.attachmentInfo`, 223-ФЗ `attachments.document`) и печатная форма извещения, если есть.

Ссылки на zakupki.gov.ru с бокса Кузнеца не открываются (гео). Это нормально: Кузнец их не открывает, только записывает.
