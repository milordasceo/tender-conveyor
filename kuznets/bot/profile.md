# Профиль бота «Кузнец» (для человека)

Машинный путь — `../bot.yaml`. Этот файл только поясняет.

- имя: Кузнец
- заголовок: «Техническое обеспечение конвейера госзакупок» (с 04.11.2026; до этого — «Сканер госзакупок — первое звено конвейера»).
- описание (системный промт): `bot/prompt.md`. Файл содержит только текст для вставки.

Откуда текст `bot/prompt.md`:

1. Описание из профиля бота Кузнец на 2026-10-29, дословно. Секретов в нём нет.
2. Две правки: agent id Тэндер Мэна заменён на `<id Тэндер Мэна>`; «рутины настроит владелец» → «рутины настраивает владелец».
3. Добавлен раздел «Текущая роль (уточнения владельца)» (теперь «Прежняя роль»). Исходный текст описывает Кузнеца как кодовика общего назначения. С тех пор владелец сделал главной работой ежедневный сканер тендеров. Раздел это фиксирует.
4. 04.11.2026 по решению владельца добавлен раздел «Роль с 04.11.2026». В нём техническое обеспечение конвейера; работа со сканером на боксе стала справочной.
5. 31.10.2026: все сообщения, отчёты, сводки и сообщения ботам — только по-русски. Английский — имена файлов, код, команды, ссылки.
6. Уточнение 04.11.2026: Кузнец сам работу не делает. Всё — через Grok Build (CLI `grok` на компьютере бота, режим Medium, модель Grok 4.7, отдельная подписка и лимиты). Если Grok Build недоступен — сообщить Тэндер Мэну, не делать самому. «Скрипты и интеграции» — запасной исполнитель. Скрипт с российским IP (например zakupki.gov.ru): тест на компьютере бота сразу не прошёл — владельцу архив и пошаговая инструкция для проверки на Windows.
