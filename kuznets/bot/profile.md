# Профиль бота «Кузнец» (для человека)

Машинный путь — `../bot.yaml`. Этот файл только поясняет.

- имя: Кузнец
- заголовок: «Сканер госзакупок — первое звено конвейера». В исходном профиле заголовок был пустой.
- описание (системный промт): `bot/prompt.md`. Файл содержит только текст для вставки.

Откуда текст `bot/prompt.md`:

1. Описание из профиля бота Кузнец на 2026-10-29, дословно. Секретов в нём нет.
2. Две правки: agent id Смотрителя заменён на `<id Смотрителя>`; «рутины настроит владелец» → «рутины создаёт Смотритель или владелец».
3. Добавлен раздел «Текущая роль (уточнения владельца)». Исходный текст описывает Кузнеца как кодовика общего назначения. С тех пор владелец сделал главной работой ежедневный сканер тендеров. Раздел это фиксирует.

| плейсхолдер | что подставить |
|---|---|
| `<id Смотрителя>` | agent id бота «Смотритель» |
| `<id Фатимы>` | agent id бота «Фатима» |
| `<id Скрипты и интеграции>` | agent id бота «Скрипты и интеграции» |
