# Рутина «Утренний скан госзакупок» (для человека)

Машинный путь — `../bot.yaml`, раздел `routines`. Текст промта для вставки — `bot/routine_prompt.md` (только текст, без обвязки).

- имя: «Утренний скан госзакупок»
- расписание: `0 7 * * *` — каждый день в 07:00 по часовому поясу бокса. Владелец подтверждает время. На старом боксе часы стояли в `Asia/Krasnoyarsk` (UTC+7, как Новосибирск). На новом боксе проверить `date`.
- бот: Кузнец
- включать последней, после проверки (`../INSTALL_BY_BOT.md`, шаг 9).

## Команда

```bash
cd /home/box/gosplan/scripts && ../.venv/bin/python gosplan_scanner.py -c config.novosibirsk.yaml --remote 'gosplan:Госзакупки/Сток'
```

- `--remote` обязателен: `export.remote` в конфиге не задан.
- `state_dir` в конфиге не задан → реестр и `run_report.json` в `/home/box/gosplan/scripts/state`. Переменная `GOSPLAN_STATE_DIR` важнее конфига. В рутине её не задавать.
- stdout: три строки `найдено / новых / выгружено`. stderr: лог и `pending: осталось N`.
- код выхода: `0` — очередь пуста; `3` — очередь не пуста, доберёт следующий запуск; другой — ошибка.
