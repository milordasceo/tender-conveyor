# Рутины Кузнеца (для человека)

Машинный путь — `../bot.yaml`, раздел `routines`. Тексты для вставки — `bot/routine_prompt.md` и `bot/routine_hourly_prompt.md` (только текст, без обвязки).

| имя | cron | промт | что делает |
|---|---|---|---|
| Утренний скан госзакупок | `0 7 * * *` | `bot/routine_prompt.md` | `gosplan_drain.py daily`: очередь пуста — поиск и запуск добора; не пуста — только проверка добора |
| Почасовая проверка добора | `0 * * * *` | `bot/routine_hourly_prompt.md` | `gosplan_drain.py status`; перезапуск добора; сообщение только при проблеме или когда «Сток» догружен |

- Время — по часовому поясу бокса. Владелец подтверждает. На старом боксе часы в `Asia/Krasnoyarsk` (UTC+7). На новом проверить `date`.
- Включать последними, после проверки (`../INSTALL_BY_BOT.md`).

## Добор очереди

Очередь `pending` не выгружается одной длинной пачкой. Её выгружает фоновый процесс по одной закупке:

```bash
cd /home/box/gosplan/scripts && ./drain_start.sh            # запустить в фоне (идемпотентно)
../.venv/bin/python gosplan_drain.py status                  # состояние
```

Внутри — цикл `gosplan_scanner.py -c config.novosibirsk.yaml --remote 'gosplan:Госзакупки/Сток' --limit 1`, пауза 30 с старт-к-старту. Подробно — `../README.md`, раздел «Добор очереди».
