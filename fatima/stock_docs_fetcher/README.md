# Загрузчик документов из «Сток» в «Бланки»

## Назначение

Программа крутится на Windows-ПК, где стоит Google Drive for desktop. Раз в `scan_interval_sec` секунд смотрит локальную папку **Сток**. Каждая подпапка — один тендер (имя папки = номер, внутри `tender.json` и `tender.md`). Для каждой подходящей папки скачивает все файлы из списка `documents` в `tender.json` в ту же папку и переносит её целиком в **Бланки**.

Папки с ошибками остаются в Стоке и повторяются позже; одна сломанная папка не блокирует остальные.

Если в `tender.json` нет списка `documents`, он не список или список пустой, папку **не** переносят: в `docs_status.json` пишется ошибка `нет документов в tender.json`, это считается попыткой (те же `retry_delay_min` / `max_attempts`). Нет файла `tender.json` или он не JSON — папка пропускается до следующего обхода, без попытки; в лог это пишется один раз за запуск.

Имя вроде «Протокол от 12.10» не считается файлом `.10`: расширение берётся из заголовков ответа, получится `Протокол от 12.10.pdf`. Печатная форма извещения без расширения по-прежнему сохраняется как HTML. Если ждали docx/pdf и пришла HTML-страница (ошибка сайта), файл не сохраняется.

## Быстрый старт (Windows)

1. Поставьте Python 3.10+ с python.org, отметьте «Add python.exe to PATH».
2. Распакуйте папку куда угодно, например `C:\tools\stock_docs_fetcher`. Не переносите её после установки: автозапуск смотрит на этот путь.
3. Запустите `INSTALL.bat`. Он ставит зависимости, сам находит «Госзакупки\Сток» и «Бланки» на Google Диске (или спрашивает путь), включает автозапуск при входе в windows и сразу запускает загрузчик в фоне.
4. `STATUS.bat` показывает, работает ли загрузчик, и последние строки лога.
5. `UNINSTALL.bat` останавливает загрузчик и убирает автозапуск.
6. `TEST.bat` — один ручной проход с выводом в окно.

Интервал проверки Стока — `scan_interval_sec` в `config.json` (по умолчанию 60 с). Сертификат zakupki.gov.ru выдан российским УЦ: скрипт берёт корни из хранилища windows (пакет truststore), а для хостов из `ssl_fallback_hosts` при ошибке сертификата качает без проверки.

## Установка на Windows

1. Поставьте Python 3.10 или новее с [python.org](https://www.python.org/downloads/windows/). На шаге установки включите **Add python.exe to PATH**.
2. Откройте командную строку в папке программы и выполните:

```bat
pip install -r requirements.txt
```

Нужен только пакет `requests`. PyYAML ставить не обязательно (он нужен, если конфиг в `.yaml` / `.yml`).

## Настройка config.json

Скопируйте пример и отредактируйте пути:

```bat
copy config.example.json config.json
```

В JSON обратный слэш в путях пишется дважды: `"G:\\Мой диск\\Госзакупки\\Сток"`.

Типичный путь Google Drive for desktop: `G:\Мой диск\Госзакупки\...`.

**Зеркало и поток.** В режиме потока (stream) файлы могут не лежать на диске, пока их не открыли. Для Стока и Бланков нужен режим зеркала (mirror) либо «доступно офлайн», чтобы папки тендеров были локальными файлами, а не облачными ярлыками.

Ключи (пути `stock_dir` и `blanks_dir` обязательны, остальные можно не писать):

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `stock_dir` | — | Папка «Сток» (локальный путь) |
| `blanks_dir` | — | Папка «Бланки» |
| `scan_interval_sec` | 60 | Пауза между обходами Стока, секунды |
| `download_pause_sec` | 3 | Пауза между скачиваниями файлов, секунды |
| `request_timeout_sec` | 60 | Таймаут соединения и чтения HTTP, секунды |
| `http_retries` | 3 | Повторы при обрыве, таймауте, 5xx и 429 |
| `retry_backoff_sec` | 5 | База экспоненциальной паузы между HTTP-повторами |
| `max_file_size_mb` | 200 | Максимальный размер одного файла, МБ |
| `retry_delay_min` | 30 | Минимум минут до следующей попытки по папке с ошибкой |
| `max_attempts` | 5 | После стольких неудач папка помечается `failed` и больше не берётся |
| `user_agent` | Chrome на Windows | Заголовок User-Agent |
| `log_file` | `stock_docs_fetcher.log` | Лог; относительный путь — от папки скрипта |
| `log_max_bytes` | 5242880 (5 МБ) | Размер файла лога до ротации |
| `log_backups` | 5 | Число старых файлов лога |
| `lock_file` | `stock_docs_fetcher.lock` | Блокировка одного экземпляра; относительный путь — от папки скрипта |
| `verify_ssl` | true | Проверка HTTPS-сертификатов |

Относительные пути `stock_dir` и `blanks_dir` считаются от каталога файла конфига. Конфиг по умолчанию — `config.json` рядом со скриптом. Допустимы `.yaml` / `.yml`, если установлен PyYAML.

## Запуск

```bat
python stock_docs_fetcher.py
```

Работает непрерывно, пока не нажмёте Ctrl+C (выход без ошибки).

Разовый проход по текущим папкам и выход с кодом 0:

```bat
python stock_docs_fetcher.py --once
```

Другой файл настроек:

```bat
python stock_docs_fetcher.py --config D:\tools\fetcher\config.json
```

Можно вместе: `--config PATH --once`.

### Пример вызова и вывода

```bat
python stock_docs_fetcher.py --once
```

```
[2026-10-29 04:40:01] 0351200003326001418: 5/5 ok -> Бланки
[2026-10-29 04:40:12] 32616501202: 1/2 ok, ошибка (попытка 2/5), следующая после 05:10
```

На консоль — ровно одна короткая строка на обработанный тендер. Подробности — в логе.

## docs_status.json

В каждой папке тендера программа ведёт `docs_status.json` (UTF-8). Пример полей:

- `number` — номер тендера
- `state` — `pending` (ждёт / в работе), `done` (всё скачано, папка готова к переносу), `failed` (попытки исчерпаны), `skipped_exists_in_blanks` (такое имя уже есть в Бланках; это не считается попыткой)
- `attempts` / `max_attempts` — сколько раз папку уже пробовали
- `last_attempt_at`, `next_attempt_after`, `updated_at` — локальное время в ISO
- `error` — ошибка на всю папку (например `нет документов в tender.json`) или `null`
- `documents[]` — по каждому файлу: `index`, `name`, `url`, `file` (имя на диске), `size` (байты), `status` (`ok` / `error`), `error`, `attempts`, `http_status`

Файл статуса и `tender.json` / `config.json` читаются как UTF-8 с BOM (можно править в Блокноте). Запись — обычный UTF-8.

Уже скачанный файл со статусом `ok` и совпадающим размером повторно не качается. Папка переносится в Бланки только когда все документы `ok` и список не пустой. Если в Бланках уже есть папка с тем же именем, Сток не трогают и не вкладывают внутрь существующей; `docs_status.json` при этом переписывается только если содержимое (кроме `updated_at`) изменилось.

## Автозапуск

### Планировщик заданий

Подставьте свои пути к `pythonw.exe` (или к `run_fetcher.bat`) и к папке программы:

```bat
schtasks /create /tn "StockDocsFetcher" /sc onlogon /rl limited /tr "C:\Users\Имя\AppData\Local\Programs\Python\Python312\pythonw.exe C:\tools\stock_docs_fetcher\stock_docs_fetcher.py"
```

Через bat (окно консоли будет видно):

```bat
schtasks /create /tn "StockDocsFetcher" /sc onlogon /rl limited /tr "C:\tools\stock_docs_fetcher\run_fetcher.bat"
```

`pythonw.exe` не открывает чёрное окно; смотрите лог-файл.

### Папка автозагрузки

Скопируйте `run_fetcher.bat` в автозагрузку пользователя:

`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`

Файл `run_fetcher.bat` лежит рядом со скриптом: переходит в свою папку, включает UTF-8 (`chcp 65001`) и запускает `python stock_docs_fetcher.py`.

## Устранение неполадок

**zakupki.gov.ru открывается только с российских IP.** С иностранного адреса скачивание получит ошибку (часто 403). Программа должна работать на ПК в России или через российский канал.

**«Уже запущен другой экземпляр (lock: …). Выход.»** Второй процесс не стартует, код выхода 2. Оставьте один экземпляр. Если программа зависла, завершите её в Диспетчере задач; lock-файл можно не удалять — блокировка снимается при выходе процесса.

**Папка зависла в `failed`.** После `max_attempts` неудач папка больше не берётся. Чтобы попробовать снова: удалите в ней `docs_status.json` **или** в этом файле поставьте `"state": "pending"` и `"attempts": 0`.

**Папка есть в Бланках, дубликат остался в Стоке.** Так и задумано: программа не затирает Бланки и не кладёт папку внутрь уже существующей. Уберите лишнюю папку вручную (из Стока или из Бланков) и при необходимости сбросьте статус.

**Сток «пустой», хотя папки видны в Диске.** Включите зеркало / «доступно офлайн». Пока нет нормального `tender.json`, папка пропускается до следующего обхода (в лог — один раз за запуск).

**«получена html-страница вместо файла».** Сайт отдал страницу ошибки вместо документа. Папка останется в Стоке и повторится по правилам попыток. С иностранного IP это часто 403/HTML с zakupki.gov.ru.
