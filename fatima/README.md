# Фатима

Бот Grok Bot. Второе звено конвейера тендеров (госзакупки, Новосибирск): документовед.

## Файлы папки

| файл | для кого | что |
|---|---|---|
| `bot.yaml` | бот-установщик | машинный манифест: бот, промт, рутина, файлы, зависимости, раскладка Диска, шаги владельца, проверка |
| `INSTALL_BY_BOT.md` | бот-установщик | пошаговая установка с контрольными точками |
| `bot/prompt.md` | бот-установщик | только системный промт Фатимы, вставлять целиком |
| `bot/routine_prompt.md` | бот-установщик | только промт рутины «Разбор тендеров из Бланков», вставлять целиком |
| `scripts/` | бокс | проверка готовности, извлечение текста, схема и проверка `tender.json`, сборка `tender.md`, счётчик, самопроверка |
| `examples/` | все | образец разобранного тендера |
| `stock_docs_fetcher/` | windows-пк владельца | загрузчик документов «Сток» → «Бланки» (сопровождает Кузнец) |

## Роль

Фатима берёт из Google Диска «Госзакупки/Бланки» тендеры, у которых загружены все документы, читает все документы целиком, переписывает `tender.md` и `tender.json` начисто (из них данные идут в CRM) и раскладывает папки тендеров в «Госзакупки/Цены/Новосибирск/» по категориям, сразу обновляя счётчик.

Фатима НЕ делает:

- не ищет цены и поставщиков, не считает маржу — это следующий бот;
- не удаляет ничего на Диске (`delete`/`purge` — только по прямой команде владельца);
- не трогает «Госзакупки/Сток» и загрузчик;
- не берёт тендер, пока документы загружены не все;
- не выдумывает данные: чего нет в документах — «не указано»;
- не пишет заявки и письма, не платит;
- не создаёт себе рутины.

```
Кузнец ──► «Сток/<номер>» ──► загрузчик (пк владельца) ──► «Бланки/<номер>» + документы + docs_status.json
                                                              │
                                                              ▼
                                   Фатима: читает документы, чистит tender.md/json
                                                              │
                                                              ▼
                «Цены/Новосибирск/{В городе | Загород | С ограничениями}/<номер>» + счётчик.json ──► бот цен
```

## Вход

- `gosplan:Госзакупки/Бланки/<номер>/` — папка тендера: `tender.md`, `tender.json` (от Кузнеца), `docs_status.json` и документы `.doc/.docx/.pdf/.html` (от загрузчика).
- Тендер берётся, только если в `docs_status.json`: `state == "done"`, `error == null`, у всех `documents[]` `status == "ok"` (`scripts/check_ready.py`).

## Выход

- В той же папке тендера — новые `tender.json` (схема `scripts/tender.schema.json`, образец `examples/`) и `tender.md` (собран из JSON).
- Папка перенесена `rclone moveto` в `gosplan:Госзакупки/Цены/Новосибирск/<категория>/<номер>`.
- `gosplan:Госзакупки/Цены/Новосибирск/счётчик.json`: `{"В городе": N, "Загород": N, "С ограничениями": N, "обновлено": "ГГГГ-ММ-ДД ЧЧ:ММ"}` — +1 у категории сразу после переноса. Бот, который ищет цены, вычитает 1, когда забирает тендер.
- На боксе: резервные копии исходных `tender.md/json` в `/home/box/fatima/backup/<номер>/<время>/`, тексты документов в `/home/box/fatima/txt/<номер>/`.
- Короткая сводка владельцу в чате.

### Что в tender.json

Основное (номер, ссылка, предмет, заказчик и ИНН, закон, способ, площадка, окончание подачи с часовым поясом); НМЦК; адрес доставки / оказания услуги (ТЗ и извещение), город, условия; поставка (количество поставок, график, сроки, срок контракта, оплата); особые условия (лицензии и разрешения, опыт, требования к участникам, СМП/СОНО, нацрежим, обеспечение заявки, контракта и гарантии, прочее); все объекты закупки дословно (наименование, все характеристики, количество, единица, ОКПД2/КТРУ, цена за единицу и позиции, «допускается аналог» да/нет с основанием); категория и причина.

### Категории

| категория | когда |
|---|---|
| «С ограничениями» | нужна любая лицензия, разрешение, опыт или иное ограничение, не дающее участвовать (у владельца нет лицензий и опыта). Место доставки не важно |
| «В городе» | ограничений нет, доставка / услуга в Новосибирске |
| «Загород» | ограничений нет, за пределами Новосибирска |

Обеспечение, СМП/СОНО, нацрежим сами по себе не ограничение, но указываются. Подпапки «С ограничениями/Лицензии» и «С ограничениями/Опыт» есть, правило раскладки по ним не задано: пока — корень «С ограничениями».

## Как Фатима работает: шаг за шагом

1. `rclone lsf --dirs-only 'gosplan:Госзакупки/Бланки'`. Пусто — молчать.
2. По каждому номеру: `rclone cat .../docs_status.json | check_ready.py --status-file -`. Не готов — пропустить (`pending` молча, `failed`/ошибки — в сводку).
3. `rclone copy` папки в `/home/box/fatima/work/<номер>`, `check_ready.py` по локальной папке.
4. Резервная копия исходных `tender.md`, `tender.json`.
5. `extract_text.py` → тексты в `/home/box/fatima/txt/<номер>`. Чтение ВСЕХ документов целиком.
6. Новый `tender.json` → `validate_tender.py` (0 ошибок, предупреждения разобраны) → `render_md.py`.
7. `rclone copyto` обоих файлов в папку тендера, проверка `rclone cat` + `diff`.
8. Категория. Нет такого номера в месте назначения → `rclone moveto` в `Цены/Новосибирск/<категория>/<номер>`. Проверка: в «Бланках» нет, в категории есть.
9. Счётчик: `rclone copyto` вниз → `counter.py inc` → `rclone copyto` вверх → `rclone cat`. Нет файла — `counter.py init` по текущим папкам.
10. Следующий тендер, пока в «Бланках» есть готовые.

Полный текст правил — `bot/prompt.md`.

## Инструменты и скрипты

`scripts/`, на боксе `/home/box/fatima/scripts/`. Подробно — `scripts/README.md`.

| скрипт | что делает |
|---|---|
| `check_ready.py` | готовность папки по `docs_status.json` |
| `extract_text.py` | тексты из `.doc/.docx/.pdf/.html/.rtf/.odt/.xls(x)` |

Зависимости: Python 3.10+ (только стандартная библиотека), LibreOffice (`soffice`), poppler-utils (`pdftotext`), rclone. В `bot.yaml` — `deploy`, `dependencies`.

## Параметры и конфиг

Отдельного конфига нет: правила — в `bot/prompt.md`. Текущие значения: город Новосибирск; категории «В городе», «Загород», «С ограничениями»; счётчик `Цены/Новосибирск/счётчик.json`, время «обновлено» по Europe/Berlin. Меняет владелец (правка промта). В `bot.yaml` — `config`.

## Рутины

| имя | cron | часовой пояс | промт |
|---|---|---|---|
| Разбор тендеров из Бланков | `0,30 8-19 * * 1-5` (будни 08:00–19:30 каждые 30 мин, гибко ±15 мин) | Europe/Berlin | `bot/routine_prompt.md` |

Сейчас на паузе. После установки рутина создаётся выключенной и включается по команде владельца. Ночью и в выходные проверок нет.

## Каналы связи

- Владельцу — одна короткая сводка в чате после разбора: сколько разобрано, номер → категория, проблемы одной строкой.
- Нечего разбирать — молчит.
- Кузнец — первое звено; настраивает rclone remote `gosplan:` и сопровождает загрузчик. Проблемы с доступом rclone или загрузчиком Фатима пишет строкой в сводке владельцу.
- Бот, который ищет цены, — следующее звено; связь через папки «Цены/Новосибирск» и счётчик, без сообщений.

## Секреты и как получить их заново

Своих секретов нет. Нужен rclone remote `gosplan:` с доступом к Drive; на новом аккаунте его настраивает Кузнец (`kuznets/`). Конфиг rclone Фатима не читает, не показывает и не копирует. В `bot.yaml` — `secrets: []`, `owner_steps.rclone_ready`.

## Установка с нуля

Пошагово — `INSTALL_BY_BOT.md`. Коротко:

1. Создать бота «Фатима», системный промт — весь `bot/prompt.md`.
2. Скопировать `scripts/` и `examples/` в `/home/box/fatima/`, создать `/home/box/fatima/{work,txt,backup,state}`.
3. Поставить LibreOffice, poppler-utils, rclone (если нет).
4. Убедиться, что Кузнец настроил `gosplan:` (`rclone lsd gosplan:Госзакупки`).
5. Проверка (`bot.yaml` → `verification`).
6. Рутина из `bot/routine_prompt.md` — создать выключенной, включить по команде владельца.

## Проверка работы

1. `bash /home/box/fatima/scripts/selftest.sh` → «selftest: всё прошло». Без Диска.
2. Только чтение: `rclone lsd gosplan:Госзакупки`; `counter.py count` по `rclone lsf -R`; `check_ready.py` по `docs_status.json` первых папок «Бланков».
3. Перенос и счётчик в тестовой папке `gosplan:Госзакупки/_проверка_фатимы` на копии образца, затем удалить эту тестовую папку. Боевые «Бланки», «Цены» и счётчик не меняются.

Команды и ожидания — `bot.yaml`, `verification`.

## Известные проблемы

- Сканы без текстового слоя: `extract_text.py` пишет `empty`. OCR нет — открыть картинкой или отметить в сводке.
- `moveto` на Google Диске переносит папку целиком (серверный перенос). Если в «Бланках» осталась пустая папка с номером — не удалять, сообщить владельцу.
- Счётчик правят два бота (Фатима +1, бот цен −1) через скачать-изменить-залить. При одновременной записи одна правка может потеряться. Окно — секунды; Фатима правит сразу после каждого переноса.
- В тестовом прогоне на старом аккаунте «обновлено» в счётчике записано по времени Новосибирска (UTC+7); в описании принято Europe/Berlin.
- Правило раскладки по «С ограничениями/Лицензии» и «/Опыт» не задано.
- Имя бота, который ищет цены, не названо.
- Полный цикл на Диске проверен вручную на одном тендере (0151100007126000034). Скрипты в этом цикле на Диск не пишут; перенос и счётчик на тестовой папке в рамках установки не проверены на новом аккаунте.

## Загрузчик документов stock_docs_fetcher

Скрипт для windows-пк с Google Диском для компьютера. Раз в минуту смотрит «Госзакупки/Сток». Если там есть папка тендера, качает все документы по ссылкам из `tender.json` в эту же папку, пишет `docs_status.json` и переносит папку в «Госзакупки/Бланки». Папки в «Сток» кладёт Кузнец.

Проверен вживую на 5 тендерах 29.10.2026.

### Установка

1. Поставьте Python 3.10+ с [python.org](https://www.python.org/downloads/windows/), отметьте «Add python.exe to PATH».
2. Скачайте репозиторий (Code → Download ZIP) и скопируйте папку `fatima/stock_docs_fetcher` туда, где она будет жить постоянно, например `C:\tools\stock_docs_fetcher`. После установки папку не переносить: автозапуск смотрит на этот путь.
3. Запустите `INSTALL.bat`. Он ставит зависимости, находит «Сток» и «Бланки» на Google Диске (или спрашивает путь к «Госзакупки»), включает автозапуск при входе в windows и сразу запускает загрузчик в фоне.

### Файлы

| файл | что делает |
|---|---|
| `INSTALL.bat` | установка, автозапуск, запуск в фоне |
| `STATUS.bat` | работает ли загрузчик и последние строки лога |
| `UNINSTALL.bat` | остановка и снятие автозапуска |
| `TEST.bat` | один ручной проход с выводом в окно |
| `run_fetcher.bat` | запуск в цикле с видимым окном |
| `stock_docs_fetcher.py` | сам загрузчик |
| `setup_config.py` | создаёт `config.json` |
| `autostart.py` | автозапуск через папку автозагрузки пользователя |
| `config.example.json` | пример настроек |

Подробности (настройки, `docs_status.json`, ошибки и повторы) — в `stock_docs_fetcher/README.md`.
