# Тендеры на своём компьютере (Windows)

Этот набор работает на обычном Windows-компьютере, без ботов и серверов. В нём две программы:

1. **Сканер** ищет подходящие закупки на gosplan.info и кладёт каждую в отдельную папку внутри **«Госзакупки/Сток»** на вашем Google Диске.
2. **Загрузчик** следит за папкой «Сток», скачивает документы закупки с zakupki.gov.ru и складывает их в **«Госзакупки/Бланки»**. Каждый 5-й готовый тендер (5, 10, 15…) кладётся не туда, а в **«Госзакупки/DSH/Бланки»** — копию структуры рядом с основными папками. Из «Сток» внутри DSH загрузчик ничего не берёт.

Все настройки обеих программ хранятся в одном файле: `settings.ini`.

> Сайт zakupki.gov.ru открывается только с российских интернет-адресов. На компьютере в России всё работает; если включён VPN, загрузчик может не скачать документы.

---

## Шаг 1. Установите Python

1. Откройте https://www.python.org/downloads/windows/ и скачайте последнюю версию **Python 3** (нужна 3.10 или новее).
2. Запустите установщик. **На первом экране обязательно поставьте галочку «Add python.exe to PATH»**, затем нажмите **Install Now**.
3. Если галочку пропустили, запустите установщик ещё раз, выберите **Modify** и включите «Add Python to environment variables». Или удалите Python и установите заново.

## Шаг 2. Установите Google Drive для компьютера

1. Скачайте программу: https://www.google.com/drive/download/, установите и войдите в свой аккаунт Google.
2. В «Проводнике» появится новый диск, обычно **G:**, а в нём папка **«Мой диск»**.
3. Найдите на нём папки `Госзакупки\Сток` и `Госзакупки\Бланки`. Если их нет, создайте. Рядом может лежать `Госзакупки\DSH\Бланки` — туда уходит каждый 5-й тендер. Эту папку загрузчик сам не создаёт: если её нет, он пишет предупреждение и кладёт тендер в основные «Бланки».
4. **Как скопировать путь к папке:** откройте её в «Проводнике», щёлкните по адресной строке вверху окна и скопируйте текст (Ctrl+C). Получится что-то вроде `G:\Мой диск\Госзакупки\Сток`.

> Если папка принадлежит другому человеку и вам её только открыли, она будет в разделе «Доступные мне». Чтобы она появилась на диске G:, нажмите на неё правой кнопкой на drive.google.com и выберите «Добавить ярлык на Диск».

## Шаг 3. Скачайте набор

1. Откройте https://github.com/milordasceo/tender-conveyor
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Распакуйте архив: правая кнопка → «Извлечь всё». Из распакованного архива нужна только папка **`pc_kit`**. Скопируйте её в удобное место, например `C:\pc_kit`.
   Лучше выбрать путь без русских букв и пробелов. Не кладите эту папку внутрь Google Диска.

## Шаг 4. Установка

Дважды щёлкните **`install.bat`**. Программа проверит Python и установит всё, что нужно. В конце появится «Готово».

## Шаг 5. Настройка

Откройте `settings.ini` в «Блокноте» (правая кнопка → «Открыть с помощью» → «Блокнот»), поправьте настройки и сохраните файл.

| Параметр | Что значит |
|---|---|
| `сток`, `бланки` | пути к папкам из шага 2 (вставьте скопированное) |
| `бланки_dsh` | путь к `DSH\Бланки`. Пусто = рядом с основными «Бланки»: `Госзакупки\DSH\Бланки` |
| `каждый_n` | каждый N-й готовый тендер кладётся в DSH/Бланки (по умолчанию 5). `0` — все в основные «Бланки» |
| `регион` | код региона, 54 = Новосибирская обл. |
| `город` | город по месту поставки (пусто = весь регион) |
| `ключевые_слова` | слова в названии закупки через запятую (пусто = любые) |
| `только_поставка` | `да` — брать только поставку товара; услуги, работы и аренда пропускаются |
| `слова_поставки` | что должно быть в названии (`поставк` ловит «поставка», «поставки»…) |
| `стоп_слова` | фрагменты названия через запятую, без учёта регистра: ищется подстрока (`медицин` отсекает «медицинский», `тест-полос` — «тест-полосок»). Пусто = не проверять. По умолчанию — услуги, работы, аренда и медицина (лекарства, реактивы, шприцы, дезинфекция, анализаторы и т.п.) |
| `сумма_от`, `сумма_до` | начальная цена, ₽ |
| `законы` | 44 и/или 223 |
| `виды` | `zk` = запрос котировок, `auction` = аукцион |
| `срок_от_дней`, `срок_до_дней` | сколько дней должно остаться до конца подачи заявок |
| `сканер_время` | во сколько запускать сканер каждый день |
| `сканер_каждые_минут` | запускать сканер ещё и каждые N минут (0 = не надо) |
| `загрузчик_интервал_сек` | как часто загрузчик проверяет «Сток» |

Закупки без срока подачи заявок сканер не выгружает. Перед выгрузкой каждой закупки он ещё раз проверяет срок.

## Шаг 6. Ручной запуск (проверка)

- **`test_scanner.bat`**: пробный поиск. Показывает, сколько закупок найдено, но ничего не записывает.
- **`run_scanner.bat`**: настоящий поиск и выгрузка в «Сток». В конце окно покажет три строки: найдено, новых, выгружено.
- **`run_fetcher_once.bat`**: загрузчик один раз обработает «Сток» и завершит работу.
- **`run_fetcher.bat`**: загрузчик работает, пока открыто окно.

## Шаг 7. Запуск по расписанию

Дважды щёлкните **`schedule.bat`**. В «Планировщике заданий Windows» появятся задачи:
- `TenderKit_Scanner`: сканер каждый день в указанное время;
- `TenderKit_Scanner_Repeat`: сканер каждые N минут (только если это задано в настройках);
- `TenderKit_Fetcher`: загрузчик запускается при входе в Windows и работает в фоне. Сразу после установки задачи он тоже запускается.

Если вы изменили время в `settings.ini`, запустите `schedule.bat` ещё раз. Остальные настройки применяются сами при следующем запуске.
Чтобы выключить всё, запустите **`unschedule.bat`**.

> Задачи выполняются, только когда компьютер включён и вы вошли в Windows.

## Как проверить, что всё работает

Запустите **`status.bat`**. Он покажет:
- найдены ли папки «Сток», «Бланки» и «DSH/Бланки» и сколько в них папок с закупками;
- какие задачи есть в Планировщике;
- последние строки журналов сканера и загрузчика.

Подробные журналы лежат в папке `logs` (`scanner.log`, `fetcher.log`).

## Частые проблемы

- **«python не является внутренней или внешней командой» / «Python не найден»**: при установке не поставили галочку «Add to PATH». См. шаг 1.
- **«папка Сток не найдена»**: неверный путь в `settings.ini` или не запущен Google Drive (значок должен быть в трее возле часов).
- **«Папка DSH/Бланки не найдена»**: на Диске нет `Госзакупки\DSH\Бланки` (или путь в `бланки_dsh` неверный). Загрузчик не останавливается и кладёт такие тендеры в основные «Бланки». Сток внутри DSH он не трогает.
- **«найдено: 0»**: подходящих закупок сейчас нет. Можно расширить суммы или сроки. Сканер работает с тестовым сервером gosplan.info, поэтому данные там могут быть неполными.
- **Загрузчик пишет ошибки доступа к zakupki.gov.ru**: выключите VPN. Сайт работает только из России.
- **Ошибка SSL/сертификата**: обновите Windows и Python, затем снова запустите `install.bat`.
- **Иероглифы вместо русских букв в окне**: закройте окно и запустите .bat-файл заново. Не переименовывайте .bat-файлы на русский.
- **Ошибка после правки `settings.ini`**: проверьте, что между названием параметра и значением стоит `=` и что числа написаны без пробелов.

## Что внутри (для справки)

- `kit.py`: читает `settings.ini`, создаёт `scanner/config.yaml` и `fetcher/config.json`, запускает программы и работает с Планировщиком.
- `scanner/`: сканер gosplan (копия `kuznets/scripts`).
- `fetcher/`: загрузчик документов. Берёт тендеры только из основного «Сток». Каждый N-й готовый кладёт в DSH/Бланки, остальные — в основные «Бланки».
- `state/`: список уже выгруженных закупок и счётчик загрузчика `dsh_counter.json` (сколько тендеров уже успешно разложено). Не удаляйте: без файла нумерация «каждый N-й» начнётся заново.
